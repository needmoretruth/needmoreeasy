# AI에게 건네는 프롬프트

[English](README.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [5분 시작](../getting-started.ko.md) | [문법 목록](../syntax.ko.md)

여기 있는 파일은 **하나만 통째로 복사해서 AI와의 대화 맨 앞에 붙여넣으면**,
그 AI가 NME를 처음 보더라도 바로 NME 프로그램을 써 줄 수 있게 만드는 글입니다.
ChatGPT·Claude 같은 평범한 대화창에서 그대로 동작합니다. 에이전트나 도구 설정이
필요 없습니다.

붙여넣은 다음에는 이렇게 말하면 됩니다.

> NME로 구구단 5단을 보여 주는 프로그램 만들어 줘

## 어느 것을 고를까

| 파일 | 담긴 것 | 길이 | 이럴 때 |
| --- | --- | --- | --- |
| [문장형 (추천)](nme-sentence.ko.md) | 문장형 문법 100% + 짧은 예제 | 가장 짧음 | **코딩을 처음 하는 경우. 대부분 이것 하나면 됩니다.** |
| [전체 문법](nme-all-levels.ko.md) | 문장형 + 초급 + 고급 + 모듈 + 오류 코드 | 중간 | Python을 아는 사람과 일하거나, 문장형만으로 안 되는 프로그램일 때 |
| [전체 문법 + 예제](nme-complete.ko.md) | 위 전부 + 완성된 예제 프로그램 12개 | 가장 김 | 대화창에 다 들어간다면 이것이 가장 정확합니다 |

세 파일 모두 **문장형을 중심에 두고** 씌어 있습니다. 처음 배우는 사람이 읽는
것을 기준으로 삼았기 때문입니다.

## 만들어진 방식

세 파일은 모두 컴파일러 소스에서 자동으로 만들어집니다
(`python scripts/build-ai-prompts.py`). 표에 적힌 문법은 컴파일러가 실제로
받아들이는 것이고, 예제 프로그램은 파일을 만들 때마다 **진짜 컴파일러로 돌려
보고** 그 결과를 그대로 실었습니다. 하나라도 컴파일되지 않으면 만들기가
실패하므로, 이 글이 거짓말을 할 수 없습니다.

## 결과를 확인하는 법

AI가 만들어 준 프로그램은 **needmoreeasy.com** 에 붙여넣어 바로 실행해 볼 수
있습니다. 설치가 필요 없고 휴대폰에서도 됩니다. 결과가 이상하면 그 화면에 뜨는
오류 메시지를 그대로 AI에게 다시 보여 주세요. 메시지에는 `E0102` 같은 고정된
번호가 붙어 있어서 AI가 무엇이 잘못됐는지 정확히 알 수 있습니다.
