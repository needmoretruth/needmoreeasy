# NME 0.0.1-beta.77

beta.77에서는 영어판과 한국어판의 기본 네이티브 결과물 이름이 서로
충돌하지 않게 합니다.

- `nme native build`에 `-o`가 없으면 원본 전체 줄기 뒤에 `.c`를 붙여
  `count.ko.nme`가 `count.c`와 충돌하지 않는 `count.ko.c`를 만들게 합니다.
- 원본 줄기가 `.ko`로 끝나는 경우에도 Windows 기본 출력에 `.exe`를 붙입니다.
- 명시적인 `-o` 경로의 기존 확장자 교체 동작은 유지하고, 이중 언어 쌍을 한
  폴더에서 빌드하는 CLI 회귀 테스트를 추가합니다.
