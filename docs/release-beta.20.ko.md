# NME 0.0.1-beta.20

beta.20에서는 기존의 독립 블록체인 시연을 니드모어코인 학습 프로젝트로
교체했습니다.

- 같은 교육용 암호화폐 핵심을 한국어·영어 문장형, 초급형, 고급형으로
  보여 주는 예제를 추가했습니다.
- 공통 암호화폐 제작 안내와 한국어·영어 예제 작성 표준 및 템플릿을
  추가했습니다.
- 여섯 방향 예제 매트릭스의 회귀 검사를 추가하고 기존의 독립 블록체인,
  작업증명, 서명, 합의 예제를 정리했습니다.

이는 교육용 단일 프로세스 코드이며, 실제 운영 암호화폐나 투자 안내가
아닙니다.
