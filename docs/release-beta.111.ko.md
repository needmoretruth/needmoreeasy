# NME 0.0.1-beta.111

beta.111에서는 종료되는 중첩 조건문을 네이티브 블록 뒤 흐름 분석에 반영합니다.

- 도달 가능한 계속 경로가 없는 중첩 조건문은 바깥 조건 분기를 종료한 것으로
  판단합니다. 실제로 뒤의 `return`에 도달할 수 있는 모든 경로에서 대입한
  이름을 조건부 초기화로 잘못 거부하지 않습니다.
- 반복문은 실행 횟수가 0일 수 있으므로 보수적으로 분석하며, 네이티브 함수에는
  계속 최상위 정수 `return`이 필요합니다.
- 영어·한국어 문장형·초급·혼합 고급 회귀 테스트와 네이티브 레퍼런스·가이드·문법
  안내를 함께 맞춥니다.
