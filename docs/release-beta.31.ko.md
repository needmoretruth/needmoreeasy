# NME 0.0.1-beta.31

beta.31에서는 네이티브 실행 파일 시작 실패에 별도의 안정적인 진단 코드를
부여했습니다.

- E9026 `네이티브 프로그램을 시작할 수 없습니다`를 추가하고
  `nme ko E9026`·`nme en E9026`에서 한영 설명을 제공합니다.
- E9013은 Python 명령 시작 실패 전용으로 유지합니다.
- 실행 파일을 만들지 않는 컴파일러 대역을 사용한 결정적인 Unix 회귀 검사로
  운영체제 실행 경로를 호스트 컴파일러 고장 없이 확인합니다.

언어 의미와 생성되는 Python 동작은 바뀌지 않습니다.
