# NME 0.0.1-beta.32

beta.32에서는 임시 작업 폴더 실패를 현재 폴더 읽기 오류와 분리했습니다.

- E9027 `임시 작업 폴더를 만들 수 없습니다`를 추가하고
  `nme ko E9027`·`nme en E9027`에서 한영 설명을 제공합니다.
- 가져온 모듈을 실행용으로 준비할 때 선택한 명령 언어를 유지해 한국어 실행
  실패가 한국어 우선 한영 형식으로 나옵니다.
- 임시 폴더 경로를 파일로 막는 결정적인 Unix 회귀 검사를 추가했습니다.

언어 의미와 생성되는 Python 동작은 바뀌지 않습니다.
