# NME 문법 목록

[English](syntax.md) | 한국어

[README](../README.ko.md) | [설치](install.ko.md) | [5분 시작](getting-started.ko.md) | [학습 과정](tutorial.ko.md) | [문법 안내](language.ko.md) | [가이드](guides/index.ko.md)

NME가 **실제로 받아들이는 표기를 빠짐없이** 모아 둔 목록입니다. 설명이 필요하면
[문법 안내](language.ko.md)를 보세요. 이 문서는 예제 모음이 아니라 표입니다.

이 파일은 컴파일러 소스에서 자동으로 만들어집니다
(`python scripts/build-syntax-reference.py`). 컴파일러가 받아들이는 표기가 여기에
빠져 있으면 검사가 실패하므로, 목록과 구현이 어긋날 수 없습니다.

## 읽는 법

- **단계**는 셋입니다. **문장형**은 따옴표·쉼표·괄호·등호·콜론이 없는 말이고,
  **초급**은 짧고 정확한 표기이며, **고급**은 그냥 Python입니다. 선언 없이 한 파일,
  한 줄 안에서 섞어 쓸 수 있습니다.
- **한 줄은 Python이 먼저입니다.** 어떤 줄이든 올바른 Python이면 NME는 손대지
  않습니다. 그래서 낱말 하나짜리 줄(`skip`, `멈춰`)은 Python 이름으로 남고,
  반복 블록 안에서만 NME 명령이 됩니다.
- **모든 NME 문장은 Python 한 줄이 됩니다.** 줄 수가 변하지 않으므로 오류 메시지의
  줄 번호가 내가 쓴 파일과 정확히 맞습니다.
- 표의 `만들어지는 Python`은 컴파일러가 내놓는 글자 그대로입니다.

## 1. 출력

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `안녕하세요! 말해줘` | `print("안녕하세요!")` |
| 문장형 | `보여줘 안녕하세요` | `print("안녕하세요")` |
| 문장형 | `오늘도 반가워요!` | `print("오늘도 반가워요!")` |
| 문장형 | `안녕하세요 이름! 말해줘` | `print("안녕하세요 " + str(이름) + "!")` |
| 초급 | `말해 "안녕"` | `print("안녕")` |
| 초급 | `말해 총합 + 1` | `print(총합 + 1)` |
| 고급 | `print("안녕")` | unchanged |

**글이 되는가, 코드가 되는가.** 동작 단어 뒤가 올바른 Python 표현식이고 그 안의
이름을 프로그램이 이미 알고 있으면 **코드**로, 그렇지 않으면 **글**로 다룹니다.
`말해`와 `say`만은 반대로, 표현식을 먼저 시도합니다. 앞에서 만든 이름이 글 안에
있으면 그 자리에 값이 들어갑니다(`안녕하세요 이름!` → `"안녕하세요 " + str(이름) + "!"`).

## 2. 입력

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `이름을 물어봐 이름이 뭐예요?` | `이름 = input("이름이 뭐예요?" + " ")` |
| 문장형 | `나이를 숫자로 물어봐 몇 살이에요?` | `나이 = int(input("몇 살이에요?" + " "))` |
| 문장형 | `이름이 뭐예요?` | `이름 = input("이름이 뭐예요?" + " ")` |
| 문장형 | `몇 살이에요?` | `나이 = int(input("몇 살이에요?" + " "))` |
| 문장형 | `이름을 물어봐` | `이름 = input()` |
| 초급 | `물어봐 이름, "이름? "` | `이름 = input("이름? ")` |
| 고급 | `이름 = input()` | unchanged |

`숫자로`/`ask number`를 붙이면 `int(input(...))`이 됩니다. 나이나 개수를 묻는
질문(`몇 살이에요?`, `How old are you?`)은 붙이지 않아도 숫자로 읽습니다.
질문 뒤에 공백이 없으면 하나 붙여 줍니다.

## 3. 값 저장

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `인사는 안녕하세요` | `인사 = "안녕하세요"` |
| 문장형 | `정답은 7` | `정답 = 7` |
| 문장형 | `인사 저장 안녕하세요` | `인사 = "안녕하세요"` |
| 초급 | `저장 총합 1 + 2` | `총합 = 1 + 2` |
| 고급 | `인사 = '안녕'` | unchanged |

한국어는 조사 `은`/`는`만으로 저장이 됩니다. 영어에는 그런 조사가 없으므로
`set … to …`를 씁니다.

## 4. 값 바꾸기

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `점수에 1 더해` | `점수 = 점수 + 1` |
| 문장형 | `점수에 1 더해줘` | `점수 = 점수 + 1` |
| 문장형 | `점수 1 올려` | `점수 = 점수 + 1` |
| 문장형 | `점수에서 1 빼줘` | `점수 = 점수 - 1` |
| 문장형 | `점수에 2 곱해` | `점수 = 점수 * 2` |
| 문장형 | `점수를 2로 나눠` | `점수 = 점수 / 2` |
| 문장형 | `점수에서 1 + 2 빼줘` | `점수 = 점수 - (1 + 2)` |
| 고급 | `점수 += 1` | unchanged |

⚠ 여러 낱말짜리 값은 괄호로 묶입니다. `점수에서 1 + 2 빼줘`는
`점수 - (1 + 2)`이지 `점수 - 1 + 2`가 아닙니다.

## 5. 기다리기

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `3초 기다려` | `__import__("time").sleep(3)` |

## 10. 비교 어휘

| NME | Python | 뜻 |
| --- | --- | --- |
| `만약에 이름이 있으면` | `name` | 참인 값 / truthy |
| `만약에 이름이 없으면` | `not (name)` | 거짓인 값 / falsey |
| `만약에 점수가 10과 같으면` | `score == 10` | == |
| `만약에 점수가 10과 같지 않으면` | `score != 10` | != |
| `만약에 점수가 10보다 크면` | `score > 10` | > |
| `만약에 점수가 10보다 작으면` | `score < 10` | < |
| `만약에 점수가 10보다 크거나 같으면` | `score >= 10` | >= |
| `만약에 점수가 10보다 작거나 같으면` | `score <= 10` | <= |

## 11. 반복 제어

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `멈춰` | `break` |
| 문장형 | `여기서 멈춰` | `break` |
| 문장형 | `건너뛰어` | `continue` |
| 문장형 | `끝` | (closes the block) |

`멈춰`와 `건너뛰어`는 그 자체로 올바른 Python 이름이므로, **반복 블록 안에서만**
NME 명령이 됩니다. 블록 밖에서는 Python 그대로 남습니다.

## 12. 목록

| 단계 | NME | 만들어지는 Python |
| --- | --- | --- |
| 문장형 | `친구들은 목록 민수, 지안` | `친구들 = ["민수", "지안"]` |
| 문장형 | `친구들은 목록 민수와 지안` | `친구들 = ["민수", "지안"]` |

`목록`/`list of` 표시가 없으면 쉼표가 들어간 줄은 그냥 글입니다.
`친구들에 민수 넣어`(목록에 넣기)와 `점수에 1 더해`(값 바꾸기)는 다른 명령입니다.

## 19. 오타 복구

동작 단어와 연결어에 한해, Python이 그 줄을 거부한 다음에만 한 글자 오타를
고쳐서 다시 읽어 봅니다(넣기·빼기·바꾸기·이웃 자리 바꿈 한 번). 고칠 방법이
둘 이상이면 고치지 않고 그 자리를 짚어 알려 줍니다. **문자열과 주석은 절대
건드리지 않습니다.**
