# NME 0.0.1-beta.99

Beta99 makes Korean-first CLI diagnostics use Korean command spellings.

- Korean recovery examples use commands such as `nme 실행`, `nme 컴파일`,
  `nme 모듈`, and `nme 설치`.
- English command invocations remain English-only.
- Stable diagnostic codes and English explanations remain unchanged.
