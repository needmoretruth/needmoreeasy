# NME 0.0.1-beta.117

beta.117에서는 괄호 안에 한국어 문장형 조건 끝말을 쓰는 경우를 고칩니다.

- `동안 (준비 그리고 횟수가 2보다 작을 동안)` 같은 표기에서 닫는 괄호와 본문
  경계를 보존합니다.
- `만약 (점수가 2보다 작으면)` 같은 `if`/`elif` 조건에도 같은 공통 경계 처리를
  적용합니다.
- 영어·한국어 문장형·초급·고급 네이티브 조건이 공통 파서 경로를 계속 사용하도록
  확인합니다.
- 조건 전체 괄호는 콜론 없는 NME 문법으로 남기고, 올바른 Python 호출과 콜론 헤더는
  Python 우선순위를 유지한다는 점을 문서화합니다.
