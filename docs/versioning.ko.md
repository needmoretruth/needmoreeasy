# NME 버전 및 출시 정책

[English](versioning.md) | 한국어

[README](../README.ko.md) | [5분 시작](getting-started.ko.md) | [학습 과정](tutorial.ko.md) | [문법 안내](language.ko.md)

NME는 [유의적 버전](https://semver.org/lang/ko/)을 사용하며, 언어를 설계하는
동안에는 명시적인 베타 시험판 버전을 붙입니다.

## 현재 출시 계열

현재 버전은 `0.0.1-beta.39`이고 공개 계열은 `0.0.1-beta.1`부터 시작했습니다.
이후 공개 베타를 출시할 때마다 마지막 숫자를 하나씩 올립니다. Git 커밋이나
브랜치 푸시 자체가 곧 출시는 아니므로, 하나의 베타를 준비하는 개발 커밋들은
같은 버전을 사용할 수 있습니다.

현재 점검 내용은 [beta.39 출시 노트](release-beta.39.ko.md)에서 볼 수 있으며,
이전 베타 노트도 같은 폴더에 남아 있습니다.

출시할 때는 다음 항목을 함께 갱신해야 합니다.

- `Cargo.toml`의 워크스페이스 버전과 `Cargo.lock`의 로컬 패키지 버전
- 변경 기록과 출시 노트
- 영어 및 한국어 사용자 문서에 적힌 버전

## `1.0.0`은 저장소 소유자만 결정

`1.0.0`과 `1.0.0-*` 시험판은 저장소 소유자가 명시적으로 지시한 뒤에만 만들거나
배포할 수 있습니다. 테스트 통과, 기능 완성도, 출시 일정만으로 그 권한이
자동으로 생기지 않습니다.

그전까지 NME는 `0.x` 베타 계열을 유지합니다. 베타 중에도 호환성을 중요하게
다루며, 문법이나 생성되는 Python 동작이 바뀌면 출시 노트에 반드시 기록합니다.
