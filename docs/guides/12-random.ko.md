# 12 — 랜덤: 주사위와 선택

- 난이도: ★★☆☆☆ (2/5)
- 선수 지식: [11 — 멈춤](11-break.ko.md)
- 주제: 랜덤
- 결과물: 주사위를 굴리고 색을 고르는 프로그램

게임에는 깜짝 놀랄 일이 필요합니다. 주사위를 굴리거나 여럿 중 하나를 고르는
것은 문장 한 줄이면 됩니다. 미리 불러올 것도, 켜 둘 것도 없습니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   주사위는 1부터 6까지 무작위 숫자
   주사위 보여줘
   ```

   여러 번 실행해 보세요. 1부터 6까지 아무 숫자나 나옵니다. 영어는
   `set die to random number from 1 to 6`입니다.

2. 정해 둔 것들 중에서 하나 고르기:

   ```nme
   색은 빨강 또는 초록 또는 파랑 중에서 골라
   색 보여줘
   ```

   영어는 `set color to pick from red or green or blue`입니다.

3. 앞에서 배운 것과 섞으면 바로 게임이 됩니다:

   ```nme
   정답은 1부터 3까지 무작위 숫자
   추측을 숫자로 물어봐 1, 2, 3 중에 골라 보세요
   만약에 추측이 정답과 같으면
       맞았어요 말해줘
   아니면
       아니에요 말해줘
       정답 보여줘
   끝
   ```

4. 여러 번 굴려서 모아 둘 수도 있습니다:

   ```nme
   눈들은 목록
   3번 반복해
   눈은 1부터 6까지 무작위 숫자
   눈들에 눈 넣어
   끝
   눈들 보여줘
   ```

5. (**지금은 안 읽어도 됩니다.**) 초급 문법에서는 같은 일을 도우미 이름으로
   부릅니다. 그때는 `랜덤 사용` 한 줄로 불러온 뒤 `랜덤정수(1, 6)`처럼 씁니다.
   문장으로 쓸 때는 그 줄이 필요 없습니다.

## 직접 해보기

주사위를 두 번 굴려 둘 다 보여 주세요:

```nme
첫번째는 1부터 6까지 무작위 숫자
두번째는 1부터 6까지 무작위 숫자
첫번째 보여줘
두번째 보여줘
```

## 배운 것

- `1부터 6까지 무작위 숫자` / `random number from 1 to 6`가 주사위를 굴립니다.
- `... 중에서 골라` / `pick from ...`가 여럿 중 하나를 고릅니다.
- 문장으로 쓸 때는 무엇도 미리 불러올 필요가 없습니다.
- 무작위는 조건·반복·목록과 그대로 섞입니다. 섞으면 바로 게임이 됩니다.
- 초급 문법에서는 `랜덤 사용` 뒤에 `랜덤정수(1, 6)`처럼 부릅니다. 그것은
  나중에 [61 — 모듈](61-modules.ko.md)에서 봅니다.
