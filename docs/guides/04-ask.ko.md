# 04 — 물어보기: 대화 나누기

- 난이도: ★☆☆☆☆ (1/5)
- 선수 지식: [03 — 이야기](03-slow-story.ko.md)
- 주제: 입력
- 결과물: 이름을 물어보고 문장으로 인사하는 프로그램

듣는 프로그램입니다. `물어봐`는 사용자가 입력한 답을 읽어 이름에
저장합니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   이름을 물어봐 이름이 뭐예요?
   안녕하세요 이름! 말해줘
   ```

2. **실행**을 누르면 프로그램이 멈춰 서서 기다립니다. 아래에 나타난 칸에
   이름을 치고 **대답**을 누릅니다.

   NME는 받아 둔 답을 두 번째 문장에 저절로 끼워 넣습니다. `민수`라고
   입력하면 `안녕하세요 민수!`가 출력됩니다.

3. 영어 대화도 같습니다:

   ```nme
   ask name What is your name?
   show Hello name!
   ```

4. 가장 쉬운 첫 입력은 그냥 질문만 쓰는 것입니다. NME가 질문에서 이름을
   알아냅니다:

   ```nme
   이름이 뭐예요?
   안녕하세요 이름!
   ```

## 직접 해보기

사는 도시를 물어보고 문장으로 보여 주세요:

```nme
도시를 물어봐 어느 도시에 살아요?
도시 좋아해요! 말해줘
```

## 배운 것

- `이름을 물어봐 질문`은 입력한 답을 `이름`에 저장하고, `ask`가 영어
  동작입니다.
- 알고 있는 이름은 나중 문장에 자동으로 끼워집니다.
- `이름이 뭐예요?` 같은 평범한 질문도 이름을 만듭니다.
- `안녕하세요 이름! 말해줘`는 `안녕하세요`와 저장된 값을 출력합니다.
