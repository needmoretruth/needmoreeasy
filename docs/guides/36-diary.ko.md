# 36 — 일기: 오늘 날짜와 함께 남기기

- 선수 지식: [23 — 최고 점수](23-high-score.ko.md), [12 — 랜덤](12-random.ko.md)
- 주제: 파일
- 결과물: 오늘 날짜와 요일을 붙여 한 줄짜리 일기를 저장하고 다시 읽는 프로그램

일기에는 **언제 쓴 것인지**가 있어야 합니다. 날짜를 손으로 적으면 틀리고
빠집니다. 컴퓨터가 이미 알고 있으니 물어보면 됩니다.

> 파일을 쓰는 프로그램은 사이트에서 돌아가지 않습니다.

## 단계

1. **날짜 도구를 씁니다.** 한 줄 적으면 날짜를 묻는 말들이 생깁니다:

   ```nme
   날짜 사용 최신
   말해 오늘()
   말해 요일()
   말해 올해()
   ```

   `2026-08-19`·`수요일`·`2026` 같은 것이 나옵니다. **시계는 세계 표준시(UTC)를
   씁니다** — 나라마다 다른 시간을 쓰면 같은 프로그램이 사람마다 다른 답을
   내기 때문입니다.

2. **날짜를 이름에 담아 둡니다.** 담아 두면 여러 번 쓸 수 있습니다:

   ```nme
   날짜 사용 최신
   오늘날짜는 오늘()
   오늘요일은 요일()
   오늘날짜 말해줘
   오늘요일 말해줘
   ```

3. **날짜·요일·내용을 한 줄로 묶습니다.** [40번](40-csv.ko.md)에서
   한 것과 같은 모양입니다:

   ```nme
   오늘날짜는 "2026-08-19"
   오늘요일은 수요일
   내용은 비가 조금 내렸다
   줄들은 빈 목록
   줄들에 오늘날짜 넣어
   줄들에 오늘요일 넣어
   줄들에 내용 넣어
   한줄은 줄들을 쉼표로 이어
   한줄 말해줘
   ```

   `2026-08-19, 수요일, 비가 조금 내렸다`가 나옵니다. **날짜를 손으로 적을 때는
   따옴표가 필요합니다** — `2026-08-19`은 빼기가 섞인 셈으로 읽히기 때문입니다.
   `오늘()`이 준 것을 쓸 때는 필요 없습니다.

4. **저장하고 다시 읽어 칸을 꺼냅니다:**

   ```nme
   한줄은 "2026-08-19, 수요일, 비가 조금 내렸다"
   "일기.txt" 파일에 한줄을 저장해
   메모에 "일기.txt" 읽어서
   칸들은 메모를 쉼표로 나눈 것
   칸들 첫 번째 말해줘
   칸들 마지막 말해줘
   ```

5. 전체입니다:

   ```nme
   날짜 사용 최신
   오늘날짜는 오늘()
   오늘요일은 요일()
   내용은 비가 조금 내렸다
   줄들은 빈 목록
   줄들에 오늘날짜 넣어
   줄들에 오늘요일 넣어
   줄들에 내용 넣어
   한줄은 줄들을 쉼표로 이어
   "일기.txt" 파일에 한줄을 저장해
   메모에 "일기.txt" 읽어서
   메모 말해줘
   ```

## 직접 해보기

`며칠뒤(7)`을 넣어 「일주일 뒤」를 함께 적어 보세요. `며칠뒤(-1)`은 어제입니다.
그리고 내용을 `물어봐`로 받으면 진짜 일기가 됩니다 — 다만 **덮어씁니다.**
쌓아 두려면 읽은 것을 목록에 넣고 다시 통째로 저장해야 합니다.

## 배운 것

- `날짜 사용 최신` 한 줄이면 `오늘()`·`요일()`·`올해()`·`며칠뒤(n)`을 쓸 수 있습니다.
- 날짜는 이름에 담아 두고 여러 번 씁니다.
- 날짜·요일·내용을 쉼표로 이으면 한 줄짜리 기록이 됩니다.
- 시계는 세계 표준시(UTC)입니다. 사람마다 다른 답이 나오지 않게 하기 위해서입니다.
