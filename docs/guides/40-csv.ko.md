# 40 — CSV: 줄마다 칸이 여럿

[English](40-csv.md) | 한국어

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [38 — 이름 목록](38-name-list.ko.md)
- 주제: 파일과 자료
- 결과물: 한 줄에 칸이 여럿인 파일을 읽어 칸별로 꺼내는 프로그램

[38번](38-name-list.ko.md)은 한 줄에 하나씩 넣었습니다. 물건 이름과 개수처럼
**한 줄에 두 가지 이상**을 넣으려면 사이에 쉼표를 둡니다. 그렇게 만든 파일을
CSV라고 부릅니다.

> 파일을 쓰는 프로그램은 사이트에서 돌아가지 않습니다.

## 단계

1. **한 줄을 쉼표로 나눕니다:**

   ```nme
   글은 사과,3
   칸들은 글을 쉼표로 나눈 것
   칸들 첫 번째 말해줘
   칸들 마지막 말해줘
   ```

   `사과`와 `3`이 따로 나옵니다.

2. **줄이 여럿이면 목록에 담습니다.** 목록을 만들 때 쉼표는 항목을 가르는
   표시라서, 쉼표가 든 줄은 먼저 이름에 담아 두고 넣습니다:

   ```nme
   첫줄은 사과,3
   둘째줄은 포도,5
   줄들은 빈 목록
   줄들에 첫줄 넣어
   줄들에 둘째줄 넣어
   ```

3. **파일에 저장하고 다시 읽습니다.** 줄바꿈으로 이어 저장하고, 줄마다 나눠
   읽습니다:

   ```nme
   줄들은 목록 가, 나
   글은 줄들을 줄바꿈으로 이어
   "장부.csv" 파일에 글을 저장해
   메모에 "장부.csv" 읽어서
   읽은줄들은 메모를 줄마다 나눈 것
   ```

4. **줄마다 다시 쉼표로 나누면 칸이 나옵니다:**

   ```nme
   읽은줄들은 목록 사과,3
   읽은줄들의 한줄마다 반복해
       칸들은 한줄을 쉼표로 나눈 것
       칸들 첫 번째 말해줘
       칸들 마지막 말해줘
   끝
   ```

5. 전체입니다:

   ```nme
   첫줄은 사과,3
   둘째줄은 포도,5
   줄들은 빈 목록
   줄들에 첫줄 넣어
   줄들에 둘째줄 넣어
   글은 줄들을 줄바꿈으로 이어
   "장부.csv" 파일에 글을 저장해
   메모에 "장부.csv" 읽어서
   읽은줄들은 메모를 줄마다 나눈 것
   읽은줄들의 한줄마다 반복해
       칸들은 한줄을 쉼표로 나눈 것
       칸들 첫 번째 말해줘
       칸들 마지막 말해줘
   끝
   ```

   **나눌 때의 쉼표와 이을 때의 쉼표는 다릅니다.** 나눌 때는 쉼표 하나로
   자르고, 이을 때는 쉼표와 빈칸(`, `)을 넣습니다. 사람이 읽는 글에는 빈칸이
   있는 편이 낫고, 파일에서 자를 때는 빈칸이 없는 편이 맞기 때문입니다.

## 직접 해보기

칸을 하나 더 늘려 보세요 — `사과,3,빨강`처럼 색을 넣고, 가운데 칸을
`칸들 2번째`로 꺼내면 됩니다.

## 배운 것

- `<글>을 쉼표로 나눈 것`은 한 줄을 칸 목록으로 만듭니다.
- 목록을 만들 때 쉼표는 항목을 가르므로, 쉼표가 든 줄은 이름에 담아 넣습니다.
- 줄바꿈으로 이어 저장하고, 줄마다 나눠 읽고, 다시 쉼표로 나누면 표가 됩니다.
- 나눌 때의 쉼표는 `,`이고 이을 때는 `, `입니다.
