# 33 — 습관 기록: 날짜마다 했는지 남기기

[English](33-habit.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [시작하기](../getting-started.ko.md) | [학습 과정](../tutorial.ko.md) | [문법 안내](../language.ko.md) | [가이드](index.ko.md)

- 난이도: ★★★★☆ (4/5)
- 선수 지식: [32 — 성적부](32-grade-book.ko.md), [12 — 랜덤](12-random.ko.md)
- 주제: 프로젝트
- 결과물: 날짜마다 했는지 안 했는지를 남기고 며칠 했는지 세는 기록

습관 기록은 **날짜마다 답 하나**입니다. 그러니 [표](41-address-book.ko.md)이고,
이름은 날짜입니다. 날짜는 손으로 적지 않고 컴퓨터에게 물어봅니다.

## 단계

1. **날짜 도구를 열고 오늘·어제·그제를 구합니다.** `며칠뒤`에 음수를 주면
   지난 날입니다:

   ```nme
   날짜 사용 최신
   오늘날짜는 오늘()
   어제날짜는 며칠뒤(-1)
   그제날짜는 며칠뒤(-2)
   오늘날짜 말해줘
   어제날짜 말해줘
   그제날짜 말해줘
   ```

2. **날짜를 이름 삼아 답을 담습니다:**

   ```nme
   날짜 사용 최신
   기록은 빈 표
   오늘날짜는 오늘()
   기록에 오늘날짜를 함으로 넣어
   기록의 오늘날짜 말해줘
   ```

   `함`이 나옵니다. **이름 자리에 이름을 쓰면 그 안에 든 날짜가 이름이
   됩니다.**

3. **오늘 것은 물어봐서 담습니다:**

   ```nme
   날짜 사용 최신
   기록은 빈 표
   오늘날짜는 오늘()
   대답을 물어봐 오늘 했나요
   기록에 오늘날짜를 대답으로 넣어
   기록 개수 말해줘
   ```

4. **며칠 했는지는 훑으면서 셉니다.** 값을 꺼내 견줍니다:

   ```nme
   기록은 빈 표
   기록에 월요일을 함으로 넣어
   기록에 화요일을 안함으로 넣어
   한날수는 0
   기록의 날짜마다 반복해
       표시는 기록의 날짜
       만약에 표시가 함과 같으면
           한날수에 1 더해
       끝
   끝
   한날수 말해줘
   ```

   `1`이 나옵니다.

5. 전체입니다:

   ```nme
   날짜 사용 최신
   기록은 빈 표
   오늘날짜는 오늘()
   어제날짜는 며칠뒤(-1)
   그제날짜는 며칠뒤(-2)
   기록에 그제날짜를 함으로 넣어
   기록에 어제날짜를 안함으로 넣어
   대답을 물어봐 오늘 했나요
   기록에 오늘날짜를 대답으로 넣어
   기록의 날짜마다 반복해
       날짜 말해줘
       기록의 날짜 말해줘
   끝
   한날수는 0
   기록의 날짜마다 반복해
       표시는 기록의 날짜
       만약에 표시가 함과 같으면
           한날수에 1 더해
       끝
   끝
   한날수 말해줘
   ```

## 직접 해보기

이어서 며칠 했는지도 세어 보세요 — 오늘부터 거꾸로 하루씩 가면서 `함`이
아닐 때 `멈춰`로 나오면 됩니다. 그리고 [36번](36-diary.ko.md)처럼 파일에
남기면 프로그램을 꺼도 기록이 남습니다.

## 배운 것

- 날짜마다 답 하나는 표이고, 날짜가 이름이 됩니다.
- `며칠뒤(-1)`은 어제입니다. 음수가 지난 날입니다.
- 이름 자리에 이름을 쓰면 그 안에 든 값이 이름이 됩니다.
- 세는 것은 훑으면서 값을 꺼내 견주고 `1 더해`를 하는 일입니다.
