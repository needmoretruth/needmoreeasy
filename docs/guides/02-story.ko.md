- 주제: 이야기 묶음
- 결과물: 여러 줄짜리 이야기를 한 묶음으로 쓴 프로그램

01번에서는 줄마다 끝에 `말해줘`를 붙였습니다. 한두 줄이면 괜찮지만 이야기를
쓰려면 줄마다 같은 말을 붙이게 됩니다. `이야기:`로 묶으면 그 안의 줄은 전부
쓴 그대로 화면에 나옵니다.

## 단계

1. `story.nme` 파일을 만듭니다:

   ```nme
   이야기:
       문이 천천히 열렸습니다.
       방 안은 비어 있었습니다.
       탁자 위에 편지가 한 장 놓여 있었습니다.
   끝
   ```

   `이야기:`로 열고 `끝`으로 닫습니다. 안쪽 줄은 네 칸 들여씁니다. 영어는
   `story:` … `end`입니다:

   ```nme
   story:
       The door opened slowly.
       The room was empty.
       One letter lay on the table.
   end
   ```

2. 묶음 안의 빈 줄은 화면에서도 빈 줄이 됩니다. 문단을 나눌 때 그대로 쓰면
   됩니다:

   ```nme
   이야기:
       첫째 날이었습니다.

       그리고 둘째 날이 왔습니다.
   끝
   ```

3. 글자가 하나씩 나오게 하려면 앞에 `천천히`를 붙입니다. [03번](03-slow-story.ko.md)에서
   한 줄에 하던 것을 묶음 전체에 하는 것입니다:

   ```nme
   천천히 이야기:
       바람이 창을 두드렸습니다.
       아무도 대답하지 않았습니다.
   끝
   ```

4. 속도를 직접 정하려면 앞에 `몇 초씩`을 적습니다:

   ```nme
   0.15초씩 천천히 이야기:
       하나.
       둘.
       셋.
   끝
   ```

   영어는 `slow story:`, `very slow story:`, `slow story every 0.15 seconds:`입니다.

5. **묶음 안은 전부 글입니다.** 명령이 아닙니다. 이야기 안에 `3초 기다려`라고
   적으면 3초를 기다리는 것이 아니라 「3초 기다려」라는 글자가 나옵니다.
   소설에는 그 편이 맞습니다 — 등장인물이 그렇게 말할 수 있으니까요.
   정말로 기다리게 하려면 묶음을 `끝`으로 닫고 밖에서 적습니다:

   ```nme
   이야기:
       밤이 깊었습니다.
   끝
   1초 기다려
   이야기:
       그리고 문 두드리는 소리가 났습니다.
   끝
   ```

## 직접 해보기

다섯 줄짜리 이야기를 하나 쓰세요. 앞의 세 줄은 보통 속도로, 마지막 두 줄은
천천히 나오게 해 보세요.

```nme
이야기:
    아주 오래된 도서관이었습니다.
    책들은 저마다 다른 두께로 서 있었습니다.
    맨 아래 칸에 한 권만 눕혀져 있었습니다.
끝
천천히 이야기:
    그 책에는 제목이 없었습니다.
    표지를 열자 첫 줄이 이렇게 적혀 있었습니다.
끝
```

## 배운 것

- `이야기:` … `끝`은 그 안의 줄을 전부 그대로 화면에 내보냅니다.
- `천천히 이야기:`는 글자를 하나씩 내보냅니다.
- `0.15초씩 천천히 이야기:`처럼 속도를 정할 수 있습니다.
- 영어는 `story:` · `slow story:` · `slow story every 0.15 seconds:`입니다.
- 묶음 안은 명령이 아니라 전부 글입니다.
