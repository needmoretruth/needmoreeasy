# 20 — 아스키 아트 — 문자로 그리기

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [14 — 화면](14-screen.ko.md)
- 주제: 화면과 시간
- 결과물: 글자를 이어 붙여 모양을 그리는 프로그램

화면에 그림을 그리는 가장 쉬운 방법은 **글자를 여러 개 이어 붙이는 것**입니다.
별표를 다섯 개 이으면 한 줄이 되고, 줄마다 개수를 늘리면 삼각형이 됩니다.

## 단계

1. **같은 글자를 여러 개 잇습니다.** 먼저 그 글자를 이름에 담아 둡니다:

   ```nme
   별표는 *
   줄은 별표를 5개 붙인 것
   줄 말해줘
   ```

   `*****`가 나옵니다.

2. **개수를 이름으로 정할 수도 있습니다.** 이때는 숫자 자리에 이름을 쓰고
   띄어 씁니다 — `수 개`처럼:

   ```nme
   별표는 *
   수는 3
   줄은 별표를 수 개 붙인 것
   줄 말해줘
   ```

3. **줄마다 하나씩 늘리면 삼각형입니다:**

   ```nme
   별표는 *
   수는 1
   5번 반복해
       줄은 별표를 수 개 붙인 것
       줄 말해줘
       수에 1 더해
   끝
   ```

4. **줄여 가면 반대쪽입니다.** 둘을 붙이면 마름모가 됩니다:

   ```nme
   별표는 *
   수는 1
   5번 반복해
       줄은 별표를 수 개 붙인 것
       줄 말해줘
       수에 1 더해
   끝
   수는 4
   4번 반복해
       줄은 별표를 수 개 붙인 것
       줄 말해줘
       수에서 1 빼
   끝
   ```

5. [14 — 화면](14-screen.ko.md)의 문장을 섞으면 그림에 틀이 생깁니다:

   ```nme
   화면 지워
   상자로 말해줘 별 그리기
   줄 그어
   별표는 *
   수는 1
   4번 반복해
       줄은 별표를 수 개 붙인 것
       줄 말해줘
       수에 1 더해
   끝
   줄 그어
   ```

## 직접 해보기

글자를 `*` 대신 `#`이나 `♥`로 바꿔 보세요. 그리고 줄마다 두 개씩 늘려
보세요 — `수에 1 더해`를 `수에 2 더해`로 바꾸면 됩니다.

## 배운 것

- `<이름>을 <개수>개 붙인 것`이 같은 글자를 여러 개 이어 붙입니다.
  영어는 `<name> repeated <count> times`입니다.
- 개수 자리에 이름을 쓸 때는 `수 개`처럼 띄어 씁니다.
- 반복 안에서 개수를 늘리거나 줄이면 모양이 생깁니다.
- 화면 문장과 섞으면 틀이 있는 그림이 됩니다.
