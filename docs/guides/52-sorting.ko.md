# 52 — 정렬 — 목록을 순서대로

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [38 — 이름 목록](38-name-list.ko.md)
- 주제: 목록과 글
- 결과물: 목록을 작은 것부터·큰 것부터 두 방향으로 세워 보는 프로그램

목록은 적어 넣은 순서 그대로 있습니다. 그런데 보여 주고 싶은 순서는 대개
그것이 아닙니다 — 점수는 높은 것부터, 이름은 가나다순으로 보고 싶습니다.
목록을 세우는 문장은 두 개뿐입니다.

## 단계

1. **목록을 만들고 그대로 봅니다.** `쉼표로 이어`는 목록을 한 줄로 보여
   줍니다:

   ```nme
   점수들은 목록 5, 3, 9, 1
   점수들을 쉼표로 이어 말해줘
   ```

   `5, 3, 9, 1` — 적은 그대로입니다.

2. **`정렬해`가 작은 것부터 세웁니다:**

   ```nme
   점수들은 목록 5, 3, 9, 1
   점수들 정렬해
   점수들을 쉼표로 이어 말해줘
   ```

   `1, 3, 5, 9`가 나옵니다. **목록 자체가 바뀝니다.** 이 뒤로 `점수들`은
   계속 세워진 상태입니다.

3. **세운 다음에는 양 끝이 답입니다.** 작은 것부터 세웠으니 첫 번째가 가장
   작고 마지막이 가장 큽니다:

   ```nme
   점수들은 목록 5, 3, 9, 1
   점수들 정렬해
   점수들 첫 번째 말해줘
   점수들 마지막 말해줘
   ```

   `1`과 `9`가 나옵니다.

4. **`거꾸로 해`가 방향을 뒤집습니다.** 세운 목록을 뒤집으면 큰 것부터가
   됩니다:

   ```nme
   점수들은 목록 5, 3, 9, 1
   점수들 정렬해
   점수들 거꾸로 해
   점수들을 쉼표로 이어 말해줘
   ```

   `9, 5, 3, 1`입니다. 순위표는 이 순서로 씁니다.

5. **글자도 세워집니다.** 숫자면 작은 수부터, 글이면 가나다순입니다:

   ```nme
   이름들은 목록 지수, 민수, 가온
   이름들 정렬해
   이름들을 쉼표로 이어 말해줘
   ```

   `가온, 민수, 지수`가 나옵니다.

6. 전체입니다:

   ```nme
   점수들은 목록 5, 3, 9, 1
   적어 놓은 순서 말해줘
   점수들을 쉼표로 이어 말해줘
   점수들 정렬해
   작은 것부터 말해줘
   점수들을 쉼표로 이어 말해줘
   점수들 첫 번째 말해줘
   점수들 마지막 말해줘
   점수들 거꾸로 해
   큰 것부터 말해줘
   점수들을 쉼표로 이어 말해줘
   ```

## 직접 해보기

`점수들 중 가장 큰 것 말해줘`를 맨 앞, 정렬하기 전에 넣어 보세요. 세우지
않고도 가장 큰 값을 찾아 줍니다. 세우는 것은 **전부를 순서대로** 보고 싶을
때 하는 일입니다.

## 배운 것

- `<목록> 정렬해`는 작은 것부터, 글이면 가나다순으로 세웁니다.
- `<목록> 거꾸로 해`는 지금 순서를 뒤집습니다. 세운 뒤에 쓰면 큰 것부터가 됩니다.
- 둘 다 **목록 자체를 바꿉니다.** 원래 순서는 남지 않습니다.
- 세운 뒤에는 `첫 번째`가 가장 작고 `마지막`이 가장 큽니다.
