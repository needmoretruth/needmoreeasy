# 19 — 게임: 반응 속도 측정

[English](19-reaction.md) | 한국어

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [15 — 시간](15-timer.ko.md)
- 주제: 게임과 시간 재기
- 결과물: 얼마나 빨리 반응하는지 재는 프로그램

[15 — 시간](15-timer.ko.md)의 시계로 게임을 하나 만듭니다. 신호가 나온 순간
시계를 켜고, 사람이 엔터를 누르면 몇 초가 지났는지 읽으면 됩니다.

## 단계

1. **시계를 켜고 읽는 것**이 전부입니다:

   ```nme
   시간 재기 시작해
   대답을 물어봐 엔터를 누르세요
   잰시간 말해줘
   ```

   `잰시간`은 시계를 켠 뒤로 흐른 초입니다.

2. **신호를 늦게 줍니다.** 바로 물어보면 미리 누를 수 있으니 잠깐 뜸을
   들입니다:

   ```nme
   준비하세요 말해줘
   3초 기다려
   지금 엔터를 누르세요 말해줘
   ```

3. **잰 값을 이름에 담아 두면** 여러 번 쓸 수 있습니다:

   ```nme
   시간 재기 시작해
   대답을 물어봐 엔터
   걸린시간은 잰시간
   걸린시간 말해줘
   ```

4. **얼마나 빨랐는지 말해 줍니다:**

   ```nme
   걸린시간은 0.4
   만약에 걸린시간이 1보다 작으면
       아주 빠릅니다 말해줘
   아니면 만약에 걸린시간이 2보다 작으면
       괜찮습니다 말해줘
   아니면
       조금 느립니다 말해줘
   끝
   ```

5. 전체입니다:

   ```nme
   반응 속도를 재 봅니다 말해줘
   준비하세요 말해줘
   3초 기다려
   지금 엔터를 누르세요 말해줘
   시간 재기 시작해
   대답을 물어봐 엔터
   걸린시간은 잰시간
   걸린시간 말해줘
   만약에 걸린시간이 1보다 작으면
       아주 빠릅니다 말해줘
   아니면 만약에 걸린시간이 2보다 작으면
       괜찮습니다 말해줘
   아니면
       조금 느립니다 말해줘
   끝
   ```

   시계는 `잰시간`을 읽는 그 순간까지의 시간을 줍니다. 그래서 시계를 켜는
   자리가 곧 「여기서부터 잰다」는 뜻입니다.

## 직접 해보기

세 번 재서 가장 빠른 값을 보여 주세요. 잰 값을 목록에 넣고
`기록들 중 가장 작은 것 말해줘`라고 하면 됩니다 — 목록은
[05 — 저장](05-set.ko.md)에서, 가장 작은 것은
[17 — 단어 맞히기](17-word-guess.ko.md)에서 본 그것입니다.

## 배운 것

- `시간 재기 시작해`가 시계를 켜고 `잰시간`이 흐른 초를 줍니다.
- `걸린시간은 잰시간`처럼 담아 두면 여러 번 쓸 수 있습니다.
- 신호 앞에 `기다려`를 넣어야 미리 누르는 것을 막습니다.
- 잰 값은 그냥 숫자라서 조건에 그대로 넣을 수 있습니다.
