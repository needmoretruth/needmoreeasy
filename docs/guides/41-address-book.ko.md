# 41 — 표: 작은 주소록

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [38 — 이름 목록](38-name-list.ko.md)
- 주제: 자료 다루기
- 결과물: 이름으로 사는 곳을 찾는 주소록

목록은 값을 **순서대로** 담습니다. 그런데 주소록에서 알고 싶은 것은 「세
번째 사람」이 아니라 **「민수가 사는 곳」**입니다. 그럴 때 쓰는 것이
**표**입니다. 값마다 자기 이름이 붙어 있습니다.

## 단계

1. **표를 만들고 값을 넣습니다.** 넣을 때는 이름과 값을 함께 적습니다:

   ```nme
   주소록은 빈 표
   주소록에 민수를 서울로 넣어
   주소록에 지안을 부산으로 넣어
   ```

   목록의 `넣어`와 같은 낱말인데, 이름이 표이면 이름과 값 두 가지를 받습니다.

2. **이름으로 값을 꺼냅니다.** 몇 번째인지는 알 필요가 없습니다:

   ```nme
   주소록은 빈 표
   주소록에 민수를 서울로 넣어
   주소록의 민수 말해줘
   ```

   `서울`이 나옵니다. 이것이 목록과 표의 가장 큰 차이입니다.

3. **몇 개가 들어 있는지도 목록과 똑같이 묻습니다:**

   ```nme
   주소록은 빈 표
   주소록에 민수를 서울로 넣어
   주소록에 지안을 부산으로 넣어
   주소록 개수 말해줘
   ```

   `2`가 나옵니다.

4. **하나씩 훑을 때는 이름이 나옵니다.** 값은 그 이름으로 다시 꺼냅니다:

   ```nme
   주소록은 빈 표
   주소록에 민수를 서울로 넣어
   주소록에 지안을 부산으로 넣어
   주소록의 이름마다 반복해
       이름 말해줘
       주소록의 이름 말해줘
   끝
   ```

   `민수`·`서울`·`지안`·`부산` 순으로 나옵니다.

5. **있는지 묻고, 지웁니다.** 둘 다 목록과 같은 문장입니다:

   ```nme
   주소록은 빈 표
   주소록에 민수를 서울로 넣어
   만약에 주소록에 민수가 있으면
       주소록의 민수 말해줘
   끝
   주소록에서 민수 빼
   주소록 개수 말해줘
   ```

   `서울`과 `0`이 나옵니다.

6. 전체입니다:

   ```nme
   주소록은 빈 표
   주소록에 민수를 서울로 넣어
   주소록에 지안을 부산으로 넣어
   주소록에 하늘을 대구로 넣어
   주소록 개수 말해줘
   주소록의 이름마다 반복해
       이름 말해줘
       주소록의 이름 말해줘
   끝
   만약에 주소록에 지안이 있으면
       지안을 찾았습니다 말해줘
       주소록의 지안 말해줘
   끝
   주소록에서 민수 빼
   주소록 개수 말해줘
   ```

## 직접 해보기

`주소록 정렬해`를 넣어 보세요 — 거절당합니다. 표에는 **순서가 없기**
때문입니다. 첫 번째도 마지막도 없고, 이름으로만 찾습니다. 순서대로 두고
싶은 것은 목록에, 이름으로 찾고 싶은 것은 표에 담습니다.

## 배운 것

- `<이름>은 빈 표`가 표를 만듭니다. 값마다 자기 이름이 붙습니다.
- `<표>에 <이름>을 <값>으로 넣어`가 값을 넣고, `<표>의 <이름>`이 꺼냅니다.
- `개수`·`…에 …가 있으면`·`…마다 반복해`·`빼`는 목록과 **같은 문장**입니다.
  담긴 것이 무엇이냐로 뜻이 갈립니다.
- 표를 훑으면 **이름**이 나옵니다. 값은 그 이름으로 다시 꺼냅니다.
- 표에는 순서가 없어서 `정렬해`·`첫 번째`는 쓰지 않습니다.
