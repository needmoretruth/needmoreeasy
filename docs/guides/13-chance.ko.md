- 난이도: ★★☆☆☆ (2/5)
- 선수 지식: [12 — 무작위](12-random.ko.md)
- 주제: 확률
- 결과물: 정해 둔 확률로만 일어나는 일이 있는 프로그램

[12번](12-random.ko.md)의 `무작위 숫자`는 주사위를 굴리는 것이었습니다. 주사위는
여섯 면이 똑같이 나옵니다. 확률은 그것과 달리 **얼마나 자주 일어날지를 직접**
정합니다. 「백 번에 서른 번」은 `30% 확률로`라고 씁니다.

## 단계

1. `luck.nme` 파일을 만듭니다:

   ```nme
   30% 확률로 말해줘 길에서 동전을 주웠습니다
   ```

   열 번 돌리면 세 번쯤 나옵니다. 안 나오는 날도 있습니다. 영어는 이렇습니다:

   ```nme
   30% chance say You found a coin
   ```

2. 여러 줄을 그 확률에 걸려면 묶음으로 씁니다. `끝`으로 닫습니다:

   ```nme
   10% 확률로
       말해줘 하늘이 어두워집니다.
       말해줘 비가 쏟아졌습니다.
   끝
   ```

3. 소수점은 **한 자리까지** 쓸 수 있습니다:

   ```nme
   12.5% 확률로 말해줘 아주 드문 일입니다
   ```

   두 자리를 쓰면 컴파일할 때 막습니다. `12.25%`는 오류입니다 — `12.3%`처럼
   한 자리로 고쳐 적으라고 알려 줍니다. 조용히 반올림하지 않는 이유는, 쓴
   사람이 적지 않은 것을 프로그램이 정하면 안 되기 때문입니다.

   `50%`처럼 소수점을 안 쓰면 정확히 백에 오십입니다. 뒤에 `.0`을 붙일 필요가
   없습니다.

4. 확률을 **참·거짓으로 담아 둘** 수도 있습니다. 그러면 그 결과를 여러 번 쓸 수
   있습니다:

   ```nme
   비는 40% 확률
   만약에 비가 있으면
       말해줘 우산을 챙기세요.
   아니면
       말해줘 오늘은 맑습니다.
   끝
   ```

   `비`는 프로그램이 시작할 때 한 번 정해지고, 그 뒤로는 바뀌지 않습니다.
   `40% 확률로`를 두 줄에 나눠 쓰면 두 번 다시 뽑기 때문에 결과가 서로 다를 수
   있습니다. 한 번 정한 것을 여러 곳에서 쓰려면 이 방법을 씁니다.

5. `0%`는 절대 일어나지 않고, `100%`는 언제나 일어납니다. 만드는 도중에 잠깐
   껐다 켜 보고 싶을 때 쓰면 편합니다:

   ```nme
   100% 확률로 말해줘 지금은 시험 중입니다
   ```

## 직접 해보기

주사위와 확률을 같이 써 보세요. 주사위는 무엇이 나올지, 확률은 얼마나 자주
일어날지를 정합니다.

```nme
주사위는 1부터 6까지 무작위 숫자
말해줘 주사위를 굴렸습니다
주사위 말해줘
20% 확률로 말해줘 그리고 주사위가 하나 더 굴러 나왔습니다
```

## 배운 것

- `30% 확률로 …`는 백 번에 서른 번 일어납니다. 영어는 `30% chance …`입니다.
- 여러 줄을 걸려면 `30% 확률로`로 열고 `끝`으로 닫습니다.
- 소수점은 한 자리까지입니다. 두 자리는 오류로 막습니다.
- `이름은 30% 확률`은 참이거나 거짓인 값을 한 번 정해 담아 둡니다.
- `0%`는 절대, `100%`는 언제나입니다.
