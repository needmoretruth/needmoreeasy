# 29 — 플레이리스트: 순서를 섞어서 듣기

[English](29-playlist.md) | 한국어

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [12 — 랜덤](12-random.ko.md), [21 — 진행](21-progress.ko.md)
- 주제: 무작위와 확률
- 결과물: 노래 목록을 섞어 한 곡씩 순서대로 재생하는 프로그램

음악 앱의 섞기는 아무 곡이나 계속 뽑는 것이 아닙니다. 그러면 같은 곡이
연달아 나옵니다. **한 번 섞어 놓고 그 순서대로 끝까지 트는 것**입니다. 노래
목록 하나면 됩니다.

## 단계

1. **노래 목록을 만듭니다:**

   ```nme
   노래들은 목록 아리랑, 도라지, 밀양, 강강술래
   노래들을 쉼표로 이어 말해줘
   ```

   적은 순서 그대로 나옵니다.

2. **`섞어`가 순서를 뒤섞습니다.** [52번](52-sorting.ko.md)의 `정렬해`와
   같은 자리에 쓰는 문장이고, 목록 자체를 바꿉니다:

   ```nme
   노래들은 목록 아리랑, 도라지, 밀양, 강강술래
   노래들 섞어
   노래들을 쉼표로 이어 말해줘
   ```

   실행할 때마다 순서가 다릅니다. **곡이 사라지거나 겹치지는 않습니다** —
   같은 네 곡이 다른 순서로 있을 뿐입니다.

3. **섞은 다음 순서대로 틉니다.** [21번](21-progress.ko.md)의
   `순서와 함께`가 몇 번째 곡인지 알려 줍니다:

   ```nme
   노래들은 목록 아리랑, 도라지, 밀양, 강강술래
   노래들 섞어
   노래들의 노래마다 순서와 함께 반복해
       순서 말해줘
       노래 말해줘
   끝
   ```

4. **한 곡이 끝날 때까지 기다립니다.** 진짜 재생 대신 잠깐 멈추면 됩니다:

   ```nme
   노래들은 목록 아리랑, 도라지
   노래들의 노래마다 반복해
       노래 말해줘
       0.5초 기다려
   끝
   ```

5. 전체입니다:

   ```nme
   노래들은 목록 아리랑, 도라지, 밀양, 강강술래
   노래들 섞어
   오늘의 재생 순서입니다 말해줘
   노래들의 노래마다 순서와 함께 반복해
       화면 지워
       순서 말해줘
       노래 말해줘
       0.5초 기다려
   끝
   다 들었습니다 말해줘
   ```

## 직접 해보기

`노래들 섞어`를 지우고 실행해 보세요 — 늘 같은 순서입니다. 그 자리에
`노래들 정렬해`를 넣으면 가나다순이 됩니다. 세 가지가 모두 같은 자리에
들어가는 한 문장입니다.

## 배운 것

- `<목록> 섞어`는 순서를 무작위로 바꿉니다. 항목이 없어지거나 겹치지 않습니다.
- 섞기는 **한 번만** 하고 그 순서대로 트는 것이 앱이 하는 일입니다.
- `섞어`·`정렬해`·`거꾸로 해`는 모두 목록 자체를 바꾸는 같은 종류의 문장입니다.
- `순서와 함께 반복해`로 몇 번째 곡인지 함께 보여 줄 수 있습니다.
