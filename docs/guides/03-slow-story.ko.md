- 주제: 이야기·천천히 출력
- 결과물: 소설처럼 글자가 하나씩 나타나는 프로그램

`말해줘`는 한 줄을 한 번에 내보냅니다. 이야기를 들려줄 때는 글자가 하나씩
나타나는 편이 읽는 맛이 있습니다. `천천히 말해줘`가 그 일을 합니다.

## 단계

1. `story.nme` 파일을 만듭니다:

   ```nme
   천천히 말해줘 문이 천천히 열렸습니다.
   ```

   글자가 하나씩 나옵니다. 영어도 똑같습니다:

   ```nme
   say slowly The door opened slowly.
   ```

2. 더 느리게 하고 싶으면 `아주`를 붙입니다:

   ```nme
   아주 천천히 말해줘 아무도 없었습니다.
   ```

   영어는 `say very slowly Nobody was there.`입니다.

3. 속도를 직접 정할 수도 있습니다. 앞에 `몇 초씩`을 적습니다:

   ```nme
   0.2초씩 천천히 말해줘 하나. 둘. 셋.
   ```

   영어는 `say slowly every 0.2 seconds One. Two. Three.`입니다.

4. 이야기는 대개 여러 줄입니다. 사이에 `기다려`를 넣으면 숨을 쉬어 갑니다:

   ```nme
   천천히 말해줘 밤이 깊었습니다.
   1초 기다려
   천천히 말해줘 그리고 문 두드리는 소리가 났습니다.
   ```

5. 물어보기와 조건을 섞으면 읽는 사람이 이야기를 고를 수 있습니다:

   ```nme
   천천히 말해줘 문을 열까요?
   대답을 물어봐 예 또는 아니오
   만약에 대답이 예와 같으면
       천천히 말해줘 문 밖에는 눈이 내리고 있었습니다.
   아니면
       천천히 말해줘 발소리는 곧 멀어졌습니다.
   끝
   ```

## 직접 해보기

세 줄짜리 짧은 이야기를 만들어 보세요. 첫 줄은 보통 속도로, 가운데 줄은
천천히, 마지막 줄은 아주 천천히 나오게 합니다:

```nme
어느 겨울밤이었습니다 말해줘
천천히 말해줘 창밖에서 무언가 움직였습니다.
아주 천천히 말해줘 그것은 아주 오래 기다린 것이었습니다.
```

## 배운 것

- `천천히 말해줘 …`는 글자를 하나씩 내보냅니다.
- `아주 천천히 말해줘 …`는 더 느리게 내보냅니다.
- `0.2초씩 천천히 말해줘 …`처럼 속도를 직접 정할 수 있습니다.
- 영어는 `say slowly`, `say very slowly`, `say slowly every 0.2 seconds`입니다.
- 줄 사이에 `1초 기다려`를 넣으면 이야기가 숨을 쉽니다.
