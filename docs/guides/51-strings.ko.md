# 51 — 글자: 세고, 나누고, 다시 잇기

[English](51-strings.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [시작하기](../getting-started.ko.md) | [학습 과정](../tutorial.ko.md) | [문법 안내](../language.ko.md) | [가이드](index.ko.md)

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [05 — 값 저장](05-set.ko.md), [40 — CSV](40-csv.ko.md)
- 주제: 목록과 글
- 결과물: 한 문장의 글자 수를 세고, 낱말로 나누고, 다시 한 줄로 잇는 프로그램

글은 프로그램이 가장 많이 다루는 것입니다. 사람이 친 것도 글이고, 파일에서
읽은 것도 글입니다. 글에 할 수 있는 일은 크게 셋입니다 — **세기**,
**나누기**, **잇기**.

## 단계

1. **글자 수는 `길이`입니다.** 빈칸도 한 글자로 셉니다:

   ```nme
   문장은 오늘 날씨가 참 좋다
   문장 길이 말해줘
   ```

   `11`이 나옵니다.

   > 한국어에서 값이 `~습니다`로 끝나면 그 줄은 **문장으로 읽혀 그대로
   > 출력됩니다.** `문장은 참 좋습니다`가 그렇습니다 — 정말 그런 뜻일 때가
   > 많기 때문입니다. 값으로 담고 싶으면 따옴표를 씁니다.

2. **빈칸으로 나누면 낱말 목록이 됩니다.** [40번](40-csv.ko.md)에서 쉼표로
   나눈 것과 같은 문장입니다:

   ```nme
   문장은 오늘 날씨가 참 좋다
   말들은 문장을 빈칸으로 나눈 것
   말들 개수 말해줘
   말들 첫 번째 말해줘
   말들 마지막 말해줘
   ```

   `4`·`오늘`·`좋다`가 나옵니다. **나눈 결과는 목록**이라서 목록에 쓰던
   문장을 그대로 씁니다.

3. **다시 한 줄로 이을 수도 있습니다:**

   ```nme
   말들은 목록 오늘, 날씨가, 참, 좋다
   말들을 쉼표로 이어 말해줘
   말들을 빈칸으로 이어 말해줘
   ```

   `오늘, 날씨가, 참, 좋다`와 `오늘 날씨가 참 좋다`가 나옵니다.

4. **낱말 수만큼 별을 찍어 볼 수도 있습니다.** 개수를 먼저 이름에 담습니다:

   ```nme
   말들은 목록 오늘, 날씨가, 참, 좋다
   낱말수는 말들 개수
   별표는 *
   줄은 별표를 낱말수 개 붙인 것
   줄 말해줘
   ```

   `****`가 나옵니다.

5. **영어 글자는 대문자·소문자로 바꿀 수 있습니다.** 한국어에는 대소문자가
   없어서 그대로입니다:

   ```nme
   이름은 mina
   이름 대문자로 말해줘
   이름 소문자로 말해줘
   ```

   `MINA`와 `mina`가 나옵니다.

6. 전체입니다:

   ```nme
   문장은 오늘 날씨가 참 좋다
   문장 길이 말해줘
   말들은 문장을 빈칸으로 나눈 것
   말들 개수 말해줘
   말들 첫 번째 말해줘
   말들 마지막 말해줘
   말들을 쉼표로 이어 말해줘
   낱말수는 말들 개수
   별표는 *
   줄은 별표를 낱말수 개 붙인 것
   줄 말해줘
   ```

## 직접 해보기

`빈칸으로` 대신 `쉼표로` 나눠 보세요 — 빈칸이 없으니 통째로 한 덩어리가
됩니다. 나누는 표시가 글 안에 실제로 있어야 나뉩니다. 그리고 나눈 말들을
`정렬해`로 세워 보면 가나다순 낱말 목록이 됩니다.

## 배운 것

- `<글> 길이`가 글자 수입니다. 빈칸도 셉니다.
- `<글>을 빈칸으로 나눈 것`이 낱말 목록을 만듭니다. 결과는 목록입니다.
- `<목록>을 <이음말>로 이어`가 다시 한 줄로 만듭니다.
- `대문자로`·`소문자로`는 영어 글자에만 효과가 있습니다.
- 한국어 값이 `~습니다`로 끝나면 문장으로 읽힙니다. 값으로 쓰려면 따옴표를 씁니다.
