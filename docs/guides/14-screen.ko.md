# 14 — 화면: 지우고, 줄 긋고, 상자에 담기

- 난이도: ★★☆☆☆ (2/5)
- 선수 지식: [13 — 확률](13-chance.ko.md)
- 주제: 화면 꾸미기
- 결과물: 화면을 지우고, 제목을 가운데에 놓고, 상자로 감싸는 프로그램

출력이 길어지면 화면이 지저분해집니다. 화면을 정리하는 문장이 넷 있습니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   화면 지워
   ```

   앞에 나온 출력이 모두 사라집니다. 영어는 `clear the screen`입니다.

2. 가로줄로 구역을 나눕니다:

   ```nme
   줄 그어
   ```

   영어는 `draw a line`입니다.

3. 제목은 가운데에 놓으면 제목처럼 보입니다:

   ```nme
   가운데 말해줘 오늘의 차림표
   ```

   영어는 `say in the middle Today's menu`입니다.

4. 눈에 띄어야 하는 문장은 상자로 감쌉니다:

   ```nme
   상자로 말해줘 남은 시간은 3분입니다
   ```

   영어는 `say in a box Three minutes left`입니다. 한글은 글자 하나가 두 칸을
   차지하는데, 상자는 그 폭까지 세어서 그립니다.

5. 넷을 합치면 한 화면이 됩니다:

   ```nme
   화면 지워
   줄 그어
   가운데 말해줘 오늘의 차림표
   줄 그어
   상자로 말해줘 커피, 차, 물
   ```

## 직접 해보기

물어보기와 합쳐, 대답할 때마다 화면을 새로 그리는 프로그램을 만들어 보세요:

```nme
화면 지워
가운데 말해줘 이름을 알려 주세요
줄 그어
이름을 물어봐 이름
화면 지워
상자로 말해줘 반갑습니다
가운데 말해줘 이름
```

## 배운 것

- `화면 지워` / `clear the screen`은 화면을 비웁니다.
- `줄 그어` / `draw a line`은 가로줄 하나를 긋습니다.
- `가운데 말해줘 …` / `say in the middle …`은 가운데에 놓습니다.
- `상자로 말해줘 …` / `say in a box …`는 상자로 감쌉니다.
- 상자와 가운데 맞춤은 한글의 두 칸 폭을 세어서 그립니다.
