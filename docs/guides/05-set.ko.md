- 결과물: 글자·숫자·목록을 이름 붙여 저장하는 프로그램

값은 이름이 붙은 상자입니다. `은`으로 상자에 넣어 두고, 나중에
`보여줘`로 꺼냅니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   인사는 안녕하세요
   인사 보여줘
   ```

   `안녕하세요`가 출력됩니다. 이름 `인사`가 그 글자를 가리킵니다.

2. 숫자도 같습니다:

   ```nme
   정답은 7
   정답은 10
   정답 보여줘
   ```

   `정답`은 상자입니다. `10`을 넣으면 `7`을 덮어쓰므로 `10`이 출력됩니다.

3. 영어는 이름 뒤에 동작이 옵니다:

   ```nme
   set greeting to Hello
   set answer to 7
   ```

   `set ... to ...`이 영어 저장 형식입니다.

4. 동작이 이름 뒤에 와도 됩니다:

   ```nme
   이름 저장 민수
   name save Mina
   ```

5. 값이 여러 개면 **목록**으로 묶습니다. 항목은 쉼표로 나눕니다:

   ```nme
   친구들은 목록 민수, 지안
   친구들에 서준 넣어
   친구들 보여줘
   ```

   `목록` 뒤에 아무것도 쓰지 않으면 빈 목록이 되고, `넣어`로 하나씩
   담습니다. 나중에 담을 것을 모을 때 이렇게 시작합니다:

   ```nme
   할일은 목록
   할일에 청소 넣어
   할일 보여줘
   ```

   `빈 목록`이라고 적어도 같습니다. 뜻이 눈에 더 잘 보입니다:

   ```nme
   준비물은 빈 목록
   준비물에 물 넣어
   준비물 보여줘
   ```

   **이름에는 띄어쓰기를 쓸 수 없습니다.** `할 일은 목록`이라고 띄어 쓰면
   이름이 아니라 그냥 글로 읽혀서 그 문장이 그대로 출력됩니다. `할일`처럼
   붙여 쓰거나 `준비물`처럼 한 낱말을 쓰세요.

   영어는 `set friends to list of Mina, Ada`와 `append Grace to friends`입니다.

## 직접 해보기

여러분의 나이를 숫자로, 좋아하는 곳을 글자로 저장하고 둘 다 보여 주세요:

```nme
나이는 12
장소는 서울
장소 보여줘
```

## 배운 것

- `이름은 값`은 값을 저장하고, `set name to value`가 영어 형식입니다.
- 같은 이름에 새 값을 넣으면 옛 값을 덮어씁니다.
- 글자와 숫자 모두 따옴표 없이 저장합니다.
- `이름 저장 값` / `name save value` 순서도 쓸 수 있습니다.
- `친구들은 목록 민수, 지안`은 값 여러 개를 한 이름에 담고,
  `친구들에 서준 넣어`는 거기에 하나를 더합니다.
