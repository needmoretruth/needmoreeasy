# 07 — 반복: 여러 번 반복하기

- 난이도: ★★☆☆☆ (2/5)
- 선수 지식: [06 — 변경](06-update.ko.md)
- 주제: 첫걸음
- 결과물: 줄을 여러 번 실행하고, 목록을 하나씩 지나가고, 잠깐 쉬는 프로그램

컴퓨터는 같은 일을 여러 번 하는 데 아주 능숙합니다. `반복`은 한 줄이나
블록을 계속 실행합니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   3번 반복해서 다시 말해줘
   ```

   `다시`가 세 번 출력됩니다. 영어도 똑같습니다:

   ```nme
   repeat 3 times and show Again
   ```

2. 횟수가 앞에 오면 나머지 줄이 반복 출력됩니다:

   ```nme
   3번 안녕하세요
   3 times Welcome to NME
   ```

3. 여러 줄은 들여쓰기만으로 묶습니다:

   ```nme
   repeat 3 times
       show First sentence
       둘째 문장 말해줘
   ```

4. 들여쓰기는 선택 사항입니다. 블록을 닫는 줄에 `끝`(또는 `end`)을
   쓰면 됩니다:

   ```nme
   3번 반복해
   한 줄 말해줘
   다른 줄 말해줘
   끝
   ```

   영어 쌍둥이는 `repeat 3 times`와 `end`입니다.

5. 정해진 횟수 대신 **목록을 하나씩** 지나갈 수도 있습니다. 목록은
   [05 — 저장](05-set.ko.md)에서 만든 그것입니다:

   ```nme
   친구들은 목록 민수, 지안
   친구들의 친구마다 반복해
   안녕하세요 친구! 말해줘
   끝
   ```

   `친구`는 한 바퀴마다 목록의 다음 값이 됩니다. 영어는
   `for each friend in friends`입니다.

6. 반복 사이에 **몇 초 쉬어야** 할 때가 있습니다:

   ```nme
   3번 반복해
   1초 기다려
   하나 지났어요 말해줘
   끝
   ```

   영어는 `wait 1 second`이고, `wait 3 seconds`처럼 여러 초도 됩니다.

## 직접 해보기

두 언어를 섞은 인사를 다섯 번 반복해 보세요:

```nme
5번 반복해
안녕하세요! 말해줘
show Hello!
끝
```

## 배운 것

- `3번 반복해서 다시 말해줘`는 한 줄을 세 번 출력합니다.
- `3번 안녕하세요` / `3 times Welcome to NME`는 나머지 줄을 반복합니다.
- 들여쓴 블록은 들여쓴 줄 전체를 반복합니다.
- `3번 반복해` ... `끝`은 들여쓰기 없이 블록을 닫습니다.
- `친구들의 친구마다 반복해`는 목록을 하나씩 지나갑니다.
- `1초 기다려`는 그 자리에서 1초 쉽니다.
