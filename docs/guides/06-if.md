- 결과물 (Result): 조건에 따라 다른 줄을 실행하는 프로그램 / a program that runs different lines depending on a condition

Programs choose. `if` runs one set of lines when a condition is true, and
`else` runs another when it is not.

## Steps

1. Create `choose.nme`:

   ```text
   ready = True
   if ready
       show Go
   ```

   The line under `if` is indented. Because `ready` is `True`, it prints
   `Go`.

2. A whole condition fits on one line with `then`:

   ```text
   if score is greater than 10 then show You won
   ```

   Korean puts the condition ending on the comparison:

   ```text
   만약에 점수가 10보다 크면 성공 말해줘
   ```

3. Compact beginner syntax uses a colon:

   ```text
   when score == 1: say "one"
   만약 점수 == 1: 말해 "one"
   ```

4. Choices with `else` need a block. The flat form closes with `end`:

   ```text
   if score == 1
   show one
   else if score == 2
   show two
   else
   show other
   end
   ```

   The Korean block uses `아니면 만약에` and `아니면` and closes with `끝`.

## Try it yourself

Welcome a guest only when a name exists:

```text
name = "Mina"
만약에 이름이 있으면
    안녕하세요 이름 말해줘
끝
```

## What you learned

- `if condition` with an indented line runs it when the condition is true.
- `if ... then show ...` is a one-line condition; `만약에 ...면` is Korean.
- `when condition:` and `만약 조건:` are the compact beginner forms.
- `else` / `아니면` and `else if` / `아니면 만약에` add other choices.
