# 10 — 동안: 조건이 참인 동안 반복

- 주제: 고르기와 반복
- 결과물: 조건이 참인 동안 반복하는 블록

`반복`은 정해진 횟수만큼 실행합니다. `동안`은 조건이 참인 동안 계속
실행하고, 거짓이 되면 멈춥니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   점수는 0
   점수가 3보다 작을 동안
       점수 말해줘
       점수에 1 더해
   끝
   ```

   블록은 `끝`으로 닫으므로 들여쓰기는 선택입니다. `0`, `1`, `2`가
   출력되고 점수가 3이 되면 멈춥니다.

2. 영어는 `while`과 `end`를 씁니다:

   ```nme
   set score to 0
   while score is less than 3
       show score
       add 1 to score
   end
   ```

3. 한 조건 안에 영어와 한국어를 섞을 수 있습니다. 한국어 끝맺음 `동안`은
   주어 뒤에 옵니다:

   ```nme
   점수는 0
   while 점수가 3보다 작을 동안
   점수 말해줘
   점수에 1 더해
   end
   ```

4. 말하는 것처럼 한 줄 반복도 됩니다. 끝맺음을 주어에 붙입니다:

   ```nme
   준비는 참
   준비하는동안 성공 말해줘
   준비는 거짓
   ```

   마지막 줄이 조건을 거짓으로 만들어 한 바퀴만 돌고 멈춥니다. 그 줄이
   없으면 반복이 끝나지 않습니다.

## 직접 해보기

이름이 비어 있는 동안 계속 물어보는 반복을 만들어 보세요:

```nme
이름은 비어있음
이름이 비어있음과 같을 동안
    이름을 물어봐 이름이 뭐예요?
끝
```

## 배운 것

- `동안 조건` ... `끝`은 조건이 참인 동안 반복합니다.
- `while condition` ... `end`가 영어 표기입니다.
- 반복은 조건을 바꿔야 멈춥니다. 바꾸지 않으면 끝나지 않습니다.
- 말하는 한국어는 주어 뒤에 끝맺음을 붙일 수 있습니다: `준비하는동안`.
