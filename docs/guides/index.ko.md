# NME 학습 가이드

[English](index.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [시작하기](../getting-started.ko.md) | [학습 과정](../tutorial.ko.md) | [문법 안내](../language.ko.md) | [가이드](index.ko.md)

짧은 가이드 90편입니다. 앞에서부터 순서대로 읽도록 만들었고, 여덟 부로
나뉩니다. 각 편은 한 가지를 가르치고, 마지막에 직접 해 볼 것과 배운 것을
정리합니다.

**설치는 필요하지 않습니다.** 코드 덩이마다 「실행해 보기」가 있어서
[needmoreeasy.com](https://needmoreeasy.com/ko/)의 쓰는 칸으로 그대로
옮겨 갑니다. 휴대폰에서도 됩니다. 여기 실린 프로그램은 전부 진짜 컴파일러로
확인한 것입니다.

## 난이도

- ★☆☆☆☆ (1/5) — 첫날. 문장 몇 줄이면 끝납니다.
- ★★☆☆☆ (2/5) — 조건과 반복이 섞입니다. 아직 문장형만으로 됩니다.
- ★★★☆☆ (3/5) — 프로그램 하나를 통째로 만듭니다.
- ★★★★☆ (4/5) — 초급 문법이나 Python이 섞입니다.
- ★★★★★ (5/5) — 거의 Python입니다.

별은 **얼마나 어려운가**이지 번호 순서가 아닙니다. 부가 바뀌면 그 주제에서
가장 쉬운 편부터 다시 시작하고, 같은 부 안에서도 문장형으로 다시 쓴 편은
그만큼 쉬워집니다.

**문장형만으로 쓰인 편이 어디까지인지**는 언제든 재 볼 수 있습니다:

    python3 scripts/report-guide-tier.py --guides
