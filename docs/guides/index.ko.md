# NME 학습 가이드

[English](index.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [시작하기](../getting-started.ko.md) | [학습 과정](../tutorial.ko.md) | [문법 안내](../language.ko.md) | [가이드](index.ko.md)

짧은 가이드 85편입니다. 앞에서부터 순서대로 읽도록 만들었고, 뒤로 갈수록
조금씩 어려워집니다. 각 편은 한 가지를 가르치고, 마지막에 직접 해 볼 것과
배운 것을 정리합니다. 코드는 모두 `nme 검사`로 확인할 수 있습니다.

- **01–04** 첫날. 문장형만 씁니다. 따옴표도 등호도 콜론도 나오지 않습니다.
- **05–12** 반복·조건·랜덤과 명령줄 도구. 여기까지가 문장형의 전부입니다.
- **13–22** 파일·JSON·작은 프로젝트·블록체인·네트워크. 초급 문법이 섞이기 시작합니다.
- **23–52** 모듈·게임·계산기·데이터·문자열·격자. Python이 절반을 넘어갑니다.
- **53–85** 통계·검색·알고리즘·컴파일러. 사실상 Python 프로그램입니다.

## 난이도

- ★☆☆☆☆ (1/5) — 첫날, 문장형만
- ★★☆☆☆ (2/5) — 문장형에 익숙해지는 단계
- ★★★☆☆ (3/5) — 초급 문법과 파일을 섞는 단계
- ★★★★☆ (4/5) — Python이 절반을 넘는 단계
- ★★★★★ (5/5) — 거의 Python

번호가 곧 난이도입니다. 순서대로 읽으면 어려워지는 폭이 한 번에 커지지 않습니다.
