# 01 — 인사: 첫 문장 말하기

[English](01-hello.md) | 한국어

- 난이도: ★☆☆☆☆ (1/5)
- 선수 지식: 없음
- 주제: 첫걸음
- 결과물: 적은 말을 그대로 화면에 내보내는 프로그램

첫 프로그램입니다. 아무것도 설치하지 않아도 되고, 컴퓨터를 잘 몰라도 됩니다.
NME는 `말해줘` 앞에 적은 것을 그대로 화면에 내보냅니다. 따옴표도 괄호도
필요 없습니다.

## 단계

1. [needmoreeasy.com](https://needmoreeasy.com/ko/)을 엽니다. 「쓰는 칸」이
   나옵니다. 거기에 이렇게 적습니다:

   ```nme
   안녕하세요! 말해줘
   ```

   **실행**을 누르면 아래에 `안녕하세요!`가 나옵니다. 그게 전부입니다. 방금
   프로그램을 하나 쓰고 돌리셨습니다.

   여기서 무엇을 해도 고장 나지 않습니다. 쓴 것은 이 창 밖으로 나가지
   않습니다.

2. `말해줘`가 「하라는 일」이고, 그 앞이 「내보낼 말」입니다. 말을 바꿔 보세요:

   ```nme
   저는 오늘 프로그램을 처음 써 봤습니다 말해줘
   ```

3. 영어도 똑같습니다. 영어에서는 `show`가 앞에 옵니다:

   ```nme
   show Hello world!
   ```

   한 파일 안에서 한국어와 영어를 섞어 써도 됩니다. 설정할 것은 없습니다.

4. 자연스러운 한 문장이면 `말해줘` 없이도 그대로 나옵니다:

   ```nme
   오늘도 반가워요!
   Hello everyone!
   ```

5. 여러 줄을 쓰면 위에서 아래로 차례대로 나옵니다:

   ```nme
   첫 번째 줄입니다 말해줘
   두 번째 줄입니다 말해줘
   ```

6. 앞에 `#`이 붙은 줄은 **아무 일도 하지 않습니다.** 컴퓨터가 그냥 지나갑니다.
   사람이 읽으라고 남겨 두는 쪽지입니다:

   ```nme
   # 이 줄은 아무 일도 하지 않습니다.
   안녕하세요! 말해줘
   ```

   실행하면 `안녕하세요!` 한 줄만 나옵니다. `#`이 붙은 줄을 전부 지워도
   프로그램이 하는 일은 똑같습니다. 예제를 열면 맨 위에 이런 줄이 여러 개
   있는데, 그것은 프로그램의 일부가 아니라 설명입니다.

## 직접 해보기

말을 여러분의 이름이나 좋아하는 곳으로 바꾸고 다시 **실행**을 눌러 보세요.
세 줄짜리 자기소개를 만들어 보아도 좋습니다.

쓴 것을 계속 두고 싶으면 쓰는 칸 위의 **파일 1**로 옮겨 두세요. 그 파일은
브라우저에 남아 있어서, 예제를 보러 갔다 와도 사라지지 않습니다.

## 컴퓨터에 설치한 경우 (지금은 안 읽어도 됩니다)

[설치](../install.ko.md)를 마쳤다면 같은 프로그램을 파일로 돌릴 수 있습니다.
`hello.nme`라는 파일에 위의 내용을 적고:

```sh
nme 실행 hello
```

`nme r hello`는 같은 명령의 짧은 형태입니다. 배우는 동안에는 필요하지
않습니다 — 사이트에서 하는 것과 결과가 같습니다.

## 배운 것

- `말해줘` 앞에 적은 것이 화면에 나옵니다. 영어는 `show`가 앞에 옵니다.
- 문장에는 따옴표도 쉼표도 괄호도 필요 없습니다.
- 자연스러운 한 줄 문장은 그대로 나옵니다.
- 여러 줄은 위에서 아래로 차례대로 실행됩니다.
- `#`으로 시작하는 줄은 아무 일도 하지 않는, 사람이 읽는 쪽지입니다.
- 설치하지 않아도 needmoreeasy.com에서 전부 됩니다.
