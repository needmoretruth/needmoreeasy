# 17 — 단어 맞히기: 숨은 단어 게임

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [16 — 확인과 빌드](16-check-build.ko.md)
- 주제: 게임
- 결과물: 숨은 단어를 한 글자씩 맞히는 게임

2부의 첫 편입니다. 1부에서 배운 것을 하나로 모아 **여섯 번 안에 숨은 단어를
맞히는 게임**을 만듭니다. 목록, 무작위, 반복, 조건이 전부 나오고, **따옴표도
괄호도 등호도 한 번 나오지 않습니다.**

## 단계

1. **숨길 단어를 무작위로 고릅니다.** 목록을 섞고 첫 번째를 가져오면 됩니다:

   ```nme
   후보들은 목록 사과, 포도, 참외
   후보들 섞어
   정답은 후보들 첫 번째
   ```

2. **글자를 하나씩 지나갈 수 있습니다.** `글자마다 반복해`는 낱말의 글자를
   차례로 줍니다:

   ```nme
   정답은 사과
   정답의 글자마다 반복해
       글자 말해줘
   끝
   ```

3. **가려진 모습을 만듭니다.** 맞힌 글자는 그대로, 아직 못 맞힌 글자는 `_`로
   바꿔 목록에 담고 빈칸으로 이어 붙입니다:

   ```nme
   정답은 사과
   맞힌글자들은 목록 사
   보이는것은 빈 목록
   정답의 글자마다 반복해
       만약에 맞힌글자들에 글자가 있으면
           보이는것에 글자 넣어
       아니면
           보이는것에 _ 넣어
       끝
   끝
   보이는것을 빈칸으로 이어 말해줘
   ```

   `사 _`가 나옵니다.

4. **이겼는지 보는 법**은 간단합니다. 가려진 곳이 하나도 없으면 다 맞힌
   것입니다:

   ```nme
   보이는것은 목록 사, 과
   만약에 보이는것에 _가 없으면
       맞혔습니다 말해줘
   끝
   ```

5. 전체입니다. `word-guess.nme`에 넣으세요:

   ```nme
   후보들은 목록 사과, 포도, 참외
   후보들 섞어
   정답은 후보들 첫 번째
   맞힌글자들은 빈 목록
   남은기회는 6
   계속 반복해
       보이는것은 빈 목록
       정답의 글자마다 반복해
           만약에 맞힌글자들에 글자가 있으면
               보이는것에 글자 넣어
           아니면
               보이는것에 _ 넣어
           끝
       끝
       보이는것을 빈칸으로 이어 말해줘
       만약에 보이는것에 _가 없으면
           맞혔습니다 말해줘
           멈춰
       끝
       만약에 남은기회가 0과 같으면
           기회를 다 썼습니다 말해줘
           정답 말해줘
           멈춰
       끝
       남은기회 말해줘
       글자를 물어봐 글자 하나를 대 보세요
       만약에 정답에 글자가 있으면
           맞았습니다 말해줘
       아니면
           아닙니다 말해줘
           남은기회에서 1 빼
       끝
       맞힌글자들에 글자 넣어
   끝
   ```

## 직접 해보기

후보 단어를 더 넣어 보세요. 그리고 이미 대 본 글자를 또 대면 기회가 줄지
않도록 고쳐 보세요 — `만약에 맞힌글자들에 글자가 있으면` 하나면 됩니다.

## 배운 것

- 목록을 `섞어` 첫 번째를 가져오면 무작위로 하나 고른 것과 같습니다.
- `글자마다 반복해`는 낱말을 글자 하나씩 지나갑니다.
- 가려진 모습은 **목록을 만들어 이어 붙인 것**입니다.
- `…에 …가 없으면`으로 이겼는지 한 줄에 물어볼 수 있습니다.
- 이 게임 전체에 따옴표도 괄호도 등호도 없습니다.
