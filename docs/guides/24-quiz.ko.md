# 24 — 퀴즈: 문제를 내고 채점하기

[English](24-quiz.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [시작하기](../getting-started.ko.md) | [학습 과정](../tutorial.ko.md) | [문법 안내](../language.ko.md) | [가이드](index.ko.md)

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [21 — 진행](21-progress.ko.md), [23 — 최고 점수](23-high-score.ko.md)
- 주제: 게임
- 결과물: 문제를 차례로 내고 맞았는지 세어 점수를 알려 주는 퀴즈

퀴즈는 같은 일을 문제 수만큼 되풀이하는 것입니다 — 하나 물어보고, 답과
견주어 보고, 맞으면 점수를 올립니다. **문제 목록과 답 목록을 나란히** 두면
문제를 늘리는 일이 목록에 한 줄 더 쓰는 일이 됩니다.

## 단계

1. **문제와 답을 나란히 둡니다.** 같은 자리끼리 짝입니다:

   ```nme
   문제들은 목록 대한민국의 수도, 가장 큰 바다
   답들은 목록 서울, 태평양
   문제들 첫 번째 말해줘
   답들 첫 번째 말해줘
   ```

   `대한민국의 수도`와 `서울`이 나옵니다.

2. **문제를 하나씩 내면서 같은 자리의 답을 꺼냅니다:**

   ```nme
   문제들은 목록 대한민국의 수도, 가장 큰 바다
   답들은 목록 서울, 태평양
   문제들의 문제마다 순서와 함께 반복해
       답은 답들 순서 번째
       문제 말해줘
       답 말해줘
   끝
   ```

3. **물어보고 견줍니다.** `물어봐` 뒤에 이름을 쓰면 그 이름에 든 글이 질문이
   됩니다:

   ```nme
   문제는 대한민국의 수도
   답은 서울
   대답을 물어봐 문제
   만약에 대답이 답과 같으면
       맞았습니다 말해줘
   아니면
       틀렸습니다 말해줘
       답 말해줘
   끝
   ```

4. **맞을 때마다 점수를 올립니다.** 점수는 0에서 시작합니다:

   ```nme
   점수는 0
   점수에 1 더해
   점수에 1 더해
   점수 말해줘
   ```

   `2`가 나옵니다.

5. 전체입니다:

   ```nme
   문제들은 목록 대한민국의 수도, 가장 큰 바다
   답들은 목록 서울, 태평양
   점수는 0
   문제들의 문제마다 순서와 함께 반복해
       답은 답들 순서 번째
       대답을 물어봐 문제
       만약에 대답이 답과 같으면
           맞았습니다 말해줘
           점수에 1 더해
       아니면
           틀렸습니다 말해줘
           답 말해줘
       끝
   끝
   점수 말해줘
   ```

## 직접 해보기

문제와 답을 하나씩 더 넣어 보세요 — **양쪽에 다** 넣어야 짝이 맞습니다.
그다음 맨 끝에 `문제들 개수 말해줘`를 넣으면 「몇 문제 중 몇 개」인지
보여 줄 수 있습니다.

## 배운 것

- 문제 목록과 답 목록을 나란히 두면 자리로 짝이 맞습니다.
- `물어봐` 뒤에 이름을 쓰면 그 이름에 든 글이 질문이 됩니다.
- `만약에 … 같으면` / `아니면`으로 맞았는지 갈라 처리합니다.
- 점수는 `0`에서 시작해 맞을 때마다 `1 더해`로 올립니다.
