# 18 — 모험 — 작은 텍스트 게임

[English](18-adventure.md) | 한국어

[README](../../README.ko.md) | [설치](../install.ko.md) | [시작하기](../getting-started.ko.md) | [학습 과정](../tutorial.ko.md) | [문법 안내](../language.ko.md) | [가이드](index.ko.md)

- 난이도: ★★★★☆ (4/5)
- 선수 지식: [11 — 멈춤](11-break.ko.md), [12 — 랜덤](12-random.ko.md)
- 주제: 프로젝트
- 결과물: 방을 이동하며 고르는 텍스트 모험

텍스트 모험은 장소를 설명하고 다음에 무엇을 할지 묻는 프로그램입니다. 1부에서
배운 것이 여기 다 모입니다 — 묻기, 조건, 끝없는 반복, 목록, 무작위. **따옴표도
괄호도 등호도 한 번 나오지 않습니다.**

## 단계

1. 먼저 **끝나지 않는 반복**과 작은 차림표부터 만듭니다:

   ```nme
   계속 반복해
       행동을 물어봐 무엇을 할까요? 둘러보기, 그만
       만약에 행동이 그만과 같으면
           동굴을 떠났습니다 말해줘
           멈춰
       아니면 만약에 행동이 둘러보기와 같으면
           축축한 돌과 동쪽으로 난 터널이 보입니다 말해줘
       아니면
           알아듣지 못했습니다 말해줘
       끝
   끝
   ```

   `계속 반복해`는 스스로 멈추지 않습니다. 나가는 길은 `멈춰`뿐이라, 게임에서
   나가려면 `그만`이라고 대답해야 합니다.

2. **가진 것을 목록에 담습니다.** [05 — 저장](05-set.ko.md)에서 만든 그
   목록입니다:

   ```nme
   준비물은 빈 목록
   준비물에 밧줄 넣어
   준비물 개수 말해줘
   만약에 준비물에 밧줄이 있으면
       밧줄이 있습니다 말해줘
   끝
   ```

3. **주사위가 위험한 방을 정합니다.** 굴린 값이 3보다 크면 밧줄을 얻습니다:

   ```nme
   눈은 1부터 6까지 무작위 숫자
   눈 말해줘
   만약에 눈이 3보다 크면
       밧줄을 찾았습니다 말해줘
   아니면
       아무것도 없습니다 말해줘
   끝
   ```

4. **이기는 조건은 가진 것으로 정합니다.** 밧줄이 있으면 문이 열리고, 없으면
   잠겨 있습니다:

   ```nme
   준비물은 빈 목록
   만약에 준비물에 밧줄이 있으면
       문이 열렸습니다 말해줘
   아니면
       문이 잠겨 있습니다 말해줘
   끝
   ```

5. 넷을 합치면 게임입니다. `adventure.nme`에 통째로 넣습니다:

   ```nme
   준비물은 빈 목록
   어두운 동굴에서 눈을 떴습니다 말해줘
   계속 반복해
       행동을 물어봐 무엇을 할까요? 둘러보기, 동쪽, 주사위, 그만
       만약에 행동이 그만과 같으면
           동굴을 떠났습니다 말해줘
           멈춰
       아니면 만약에 행동이 둘러보기와 같으면
           축축한 돌과 동쪽으로 난 터널이 보입니다 말해줘
       아니면 만약에 행동이 주사위와 같으면
           눈은 1부터 6까지 무작위 숫자
           눈 말해줘
           만약에 눈이 3보다 크면
               밧줄을 찾았습니다 말해줘
               준비물에 밧줄 넣어
           아니면
               아무것도 없습니다 말해줘
           끝
       아니면 만약에 행동이 동쪽과 같으면
           돌방에 들어섰습니다 말해줘
           만약에 준비물에 밧줄이 있으면
               문이 열렸습니다 말해줘
               멈춰
           아니면
               문이 잠겨 있습니다 말해줘
           끝
       아니면
           알아듣지 못했습니다 말해줘
       끝
   끝
   ```

   `둘러보기` → `주사위`를 밧줄이 나올 때까지 → `동쪽` 순서로 대답하면
   이깁니다. 주사위가 무작위라 몇 번 굴려야 하는지는 그때그때 다릅니다.

## 직접 해보기

방을 하나 더 만들어 보세요. `서쪽`이라는 대답을 받아 강가로 가게 하고, 거기서
주사위를 굴려 `동전`을 얻게 합니다. 그리고 문이 열리려면 밧줄과 동전이 **둘 다**
있어야 하도록 바꿔 보세요 — [09 — 그리고/또는](09-and-or.ko.md)의 `그리고`를
쓰면 됩니다.

## 배운 것

- `계속 반복해`는 끝나지 않는 반복이고, 나가는 길은 `멈춰`뿐입니다.
- 대답을 `만약에 … 아니면 만약에 …` 사슬로 나누면 그것이 차림표입니다.
- 목록이 가진 물건이 됩니다: `넣어`로 담고 `…에 …가 있으면`으로 확인합니다.
- 무작위 숫자가 실행마다 다른 이야기를 만듭니다.
- 이 게임 전체에 따옴표도 괄호도 등호도 없습니다.
