# 43 — 글 통계: 글자 수, 낱말 수, 가장 긴 낱말

[English](43-text-stats.md) | 한국어

- 난이도: ★★★☆☆ (3/5)
- 선수 지식: [37 — 파일](37-files.ko.md), [40 — CSV](40-csv.ko.md)
- 주제: 목록과 글
- 결과물: 파일에 저장한 글을 다시 읽어 글자 수·낱말 수·가장 긴 낱말을 알려 주는 프로그램

파일에서 읽어 온 것은 글 한 덩어리입니다. 거기서 알고 싶은 것은 대개
셋입니다 — **얼마나 긴지**, **낱말이 몇 개인지**, **가장 긴 낱말이
무엇인지**.

> 파일을 쓰는 프로그램은 사이트에서 돌아가지 않습니다.

## 단계

1. **저장하고 다시 읽습니다.** [37번](37-files.ko.md)에서 한 그대로입니다:

   ```nme
   글은 오늘 날씨가 참 좋다
   "메모.txt" 파일에 글을 저장해
   메모에 "메모.txt" 읽어서
   메모 말해줘
   ```

2. **글자 수와 낱말 수는 문장 두 개입니다:**

   ```nme
   메모는 오늘 날씨가 참 좋다
   메모 길이 말해줘
   말들은 메모를 빈칸으로 나눈 것
   말들 개수 말해줘
   ```

   `11`과 `4`가 나옵니다.

3. **가장 긴 낱말은 하나씩 견주어 찾습니다.** 지금까지 가장 긴 것을 이름에
   담아 두고, 더 긴 것이 나오면 바꿉니다:

   ```nme
   말들은 목록 오늘, 날씨가, 참, 좋다
   가장긴말은 말들 첫 번째
   최대길이는 가장긴말 길이
   말들의 말마다 반복해
       이번길이는 말 길이
       만약에 이번길이가 최대길이보다 크면
           가장긴말은 말
           최대길이는 이번길이
       끝
   끝
   가장긴말 말해줘
   ```

   `날씨가`가 나옵니다. **길이는 먼저 이름에 담습니다** — `말 길이가
   가장긴말 길이보다 크면`처럼 견주는 쪽에 바로 쓸 수는 없습니다.

4. 전체입니다:

   ```nme
   글은 오늘 날씨가 참 좋다
   "메모.txt" 파일에 글을 저장해
   메모에 "메모.txt" 읽어서
   메모 길이 말해줘
   말들은 메모를 빈칸으로 나눈 것
   말들 개수 말해줘
   가장긴말은 말들 첫 번째
   최대길이는 가장긴말 길이
   말들의 말마다 반복해
       이번길이는 말 길이
       만약에 이번길이가 최대길이보다 크면
           가장긴말은 말
           최대길이는 이번길이
       끝
   끝
   가장긴말 말해줘
   최대길이 말해줘
   ```

## 직접 해보기

가장 **짧은** 낱말도 찾아 보세요 — `크면`을 `작으면`으로 바꾸면 됩니다.
그리고 줄 수도 세어 보세요: `줄들은 메모를 줄마다 나눈 것` 다음에
`줄들 개수 말해줘`입니다.

## 배운 것

- 파일에서 읽은 것은 글 한 덩어리이고, 나누어야 목록이 됩니다.
- `길이`가 글자 수, 나눈 목록의 `개수`가 낱말 수입니다.
- 가장 긴 것은 지금까지의 최고를 이름에 담아 두고 하나씩 견주어 찾습니다.
- 견주는 쪽에는 읽어 온 값을 바로 쓸 수 없어 이름에 먼저 담습니다.
