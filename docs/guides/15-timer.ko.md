- 난이도: ★★☆☆☆ (2/5)
- 선수 지식: [14 — 화면](14-screen.ko.md)
- 주제: 시간 재기·쿨타임
- 결과물: 걸린 시간을 재고, 정해진 시간 동안 다시 못 하게 막는 프로그램

게임에는 "몇 초 걸렸나"와 "아직 다시 못 씀"이 자주 필요합니다. 둘 다 문장으로
씁니다.

## 단계

1. 쓰는 칸에 이렇게 적습니다:

   ```nme
   시간 재기 시작해
   3초 기다려
   잰시간 말해줘
   ```

   `3.0`에 가까운 숫자가 나옵니다. 영어는 `start the timer`와 `show elapsed`입니다.

2. `잰시간`은 값이라서 어디에나 쓸 수 있습니다. 저장해도 되고:

   ```nme
   시간 재기 시작해
   1초 기다려
   걸린시간은 잰시간
   걸린시간 말해줘
   ```

   조건에 넣어도 됩니다:

   ```nme
   시간 재기 시작해
   만약에 잰시간이 10보다 크면
       너무 오래 걸렸습니다 말해줘
   끝
   ```

3. 시계를 켜지 않고 `잰시간`을 읽으면 컴파일할 때 막아 줍니다. 오류
   `E0226`이 나오면 앞줄에 `시간 재기 시작해`를 넣으면 됩니다.

4. **쿨타임**은 "이 동작은 몇 초 동안 다시 못 한다"는 뜻입니다. 이름을
   붙여서 겁니다:

   ```nme
   공격 쿨타임 3초 걸어
   ```

   영어는 `put attack on cooldown for 3 seconds`입니다.

5. 끝났는지 물어봅니다:

   ```nme
   공격 쿨타임 3초 걸어
   만약 공격 쿨타임이 남았으면
       아직 공격할 수 없습니다 말해줘
   끝
   ```

   반대는 `공격 쿨타임이 끝났으면`입니다. 영어는 `when attack is on cooldown`과
   `when attack is ready`입니다.

6. 끝날 때까지 기다릴 수도 있습니다:

   ```nme
   공격 쿨타임 2초 걸어
   공격 쿨타임 끝날때까지 기다려
   이제 공격할 수 있습니다 말해줘
   ```

   영어는 `wait for attack`입니다.

## 직접 해보기

문 하나에 쿨타임을 걸고, 열릴 때까지 기다린 다음 몇 초 걸렸는지 보여 주세요:

```nme
시간 재기 시작해
문 쿨타임 2초 걸어
문 쿨타임 끝날때까지 기다려
문이 열렸습니다 말해줘
잰시간 말해줘
```

## 배운 것

- `시간 재기 시작해` / `start the timer`는 시계를 켭니다.
- `잰시간` / `elapsed`는 시계를 켠 뒤 흐른 초입니다. 값이므로 어디에나 씁니다.
- `공격 쿨타임 3초 걸어` / `put attack on cooldown for 3 seconds`가 쿨타임을 겁니다.
- `공격 쿨타임이 남았으면` / `끝났으면`으로 상태를 묻습니다.
- `공격 쿨타임 끝날때까지 기다려` / `wait for attack`은 남은 시간만큼 쉽니다.
- 쿨타임 이름은 여러 개를 따로 걸 수 있습니다. 이름마다 따로 셉니다.
