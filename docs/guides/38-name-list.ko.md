- 결과물: 이름을 파일에 줄줄이 저장하고 다시 목록으로 읽는 프로그램

[37번](37-files.ko.md)은 글 한 덩이를 저장했습니다. 이름이 여럿이면 **한 줄에
하나씩** 넣어 두고, 읽을 때 다시 목록으로 되돌리는 것이 편합니다.

> 파일을 쓰는 프로그램은 사이트에서 돌아가지 않습니다. 본인 컴퓨터에서 해 보세요.

## 단계

1. **목록을 한 덩이 글로 잇습니다.** 사이에 줄바꿈을 넣으면 한 줄에 하나가
   됩니다:

   ```nme
   친구들은 목록 민수, 지안, 서준
   글은 친구들을 줄바꿈으로 이어
   글 말해줘
   ```

2. **그 글을 파일에 저장합니다:**

   ```nme
   친구들은 목록 민수, 지안, 서준
   글은 친구들을 줄바꿈으로 이어
   "이름들.txt" 파일에 글을 저장해
   ```

3. **읽어서 다시 목록으로 되돌립니다.** `줄마다 나눈 것`이 그 일을 합니다:

   ```nme
   메모에 "이름들.txt" 읽어서
   이름들은 메모를 줄마다 나눈 것
   이름들 개수 말해줘
   ```

4. **몇 번째인지와 함께 지나갈 수도 있습니다:**

   ```nme
   이름들은 목록 민수, 지안
   이름들의 이름마다 순서와 함께 반복해
       순서 말해줘
       이름 말해줘
   끝
   ```

   `순서`는 1부터 셉니다.

5. 전체입니다:

   ```nme
   친구들은 목록 민수, 지안, 서준
   글은 친구들을 줄바꿈으로 이어
   "이름들.txt" 파일에 글을 저장해
   메모에 "이름들.txt" 읽어서
   이름들은 메모를 줄마다 나눈 것
   이름들 개수 말해줘
   이름들의 이름마다 순서와 함께 반복해
       순서 말해줘
       이름 말해줘
   끝
   ```

   `이어`와 `나눈 것`은 서로 반대입니다. 목록을 글로 만들었다가 다시 목록으로
   되돌리는 것이고, 그 사이에 파일이 있습니다.

## 직접 해보기

이름을 물어봐서 목록에 넣고, 다 끝나면 파일에 저장해 보세요. 다음에 켰을 때
그 파일을 읽어 이어서 넣으면 명단이 자랍니다.

## 배운 것

- `<목록>을 줄바꿈으로 이어`는 목록을 한 줄에 하나씩 있는 글로 만듭니다.
- `<글>을 줄마다 나눈 것`은 그 글을 다시 목록으로 되돌립니다.
- 둘 사이에 파일을 두면 명단이 프로그램보다 오래 남습니다.
- `순서와 함께 반복해`는 몇 번째인지를 함께 줍니다. 1부터 셉니다.
