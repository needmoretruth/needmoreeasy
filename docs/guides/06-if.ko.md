- 주제: 조건
- 결과물: 조건에 따라 다른 줄을 실행하는 프로그램

프로그램은 선택합니다. `만약`은 조건이 참일 때 한 묶음을, `아니면`은
참이 아닐 때 다른 묶음을 실행합니다.

## 단계

1. `choose.nme` 파일을 만듭니다:

   ```text
   준비는 참
   만약에 준비가 있으면
       성공 말해줘
   ```

   `만약에` 아래 줄은 들여씁니다. `준비`가 참이므로 `성공`이 출력됩니다.

2. 조건 전체를 한 줄로 쓰려면 비교 끝맺음을 사용합니다:

   ```text
   만약에 점수가 10보다 크면 성공 말해줘
   ```

   영어는 `then`을 씁니다:

   ```text
   if score is greater than 10 then show You won
   ```

3. 간단한 초급 문법은 콜론을 사용합니다:

   ```text
   만약 점수 == 1: 말해 "하나"
   ```

4. `아니면`으로 갈리는 선택은 블록이 필요합니다. 평평한 블록은 `끝`으로
   닫습니다:

   ```text
   점수는 1
   만약에 점수가 1과 같으면
   하나 말해줘
   아니면 만약에 점수가 2와 같으면
   둘 말해줘
   아니면
   다른 것 말해줘
   끝
   ```

   영어 블록은 `else if`, `else`, `end`를 씁니다.

## 직접 해보기

이름이 있을 때만 손님을 맞이해 보세요:

```text
이름은 민수
만약에 이름이 있으면
    안녕하세요 이름 말해줘
끝
```

## 배운 것

- `만약 조건`과 들여쓴 줄은 조건이 참일 때만 실행합니다.
- `만약에 ...면 ...`은 한 줄 조건이고, `if ... then`이 영어 형식입니다.
- `만약 조건:`이 콜론을 쓰는 초급 형식이고, 영어는 `when condition:`입니다.
- `아니면` / `else`와 `아니면 만약에` / `else if`로 다른 선택을 더합니다.
