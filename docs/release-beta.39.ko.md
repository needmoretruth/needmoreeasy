# NME 0.0.1-beta.39

beta.39에서는 네이티브 결과물에도 실수로 덮어쓰지 않는 규칙을 적용합니다.

- 요청한 실행 파일이 이미 있으면 `nme native build -o`를 E9009로 거절합니다.
- 함께 만드는 C 소스가 이미 있어도 E9009로 거절하고 기존 두 파일을 그대로
  둡니다.
- 실행 파일과 생성되는 C 소스가 충돌하므로 `.c` 출력 경로는 E9003으로
  거절합니다.
- 한영 E9009 조회 설명과 회귀 검사 범위를 넓혔습니다.

언어 의미와 생성되는 Python 동작은 바뀌지 않습니다.
