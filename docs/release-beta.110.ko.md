# NME 0.0.1-beta.110

beta.110에서는 네이티브 백엔드에 실제 불리언 바인딩을 추가합니다.

- `True`/`False`와 문장형 `true`/`false`/`참`/`거짓` 리터럴을 정수와
  구별되는 정적 타입으로 이름에 대입할 수 있습니다.
- 불리언 이름을 참·거짓 `if`/`while` 조건과 같음·다름 비교에 사용하고,
  `show`로 `True`/`False`를 출력할 수 있습니다.
- 생성된 C에서 `int`를 사용하더라도 불리언 산술, `더해`/`빼` 값 변경,
  정수 전용 네이티브 함수 인자와 반환은 명확히 거부합니다.
- 영어·한국어 문장형·초급·고급 표면에서 같은 테스트를 사용하고 네이티브
  문서를 함께 맞춥니다.
