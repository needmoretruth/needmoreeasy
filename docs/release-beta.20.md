# NME 0.0.1-beta.20

Beta.20 replaces the earlier standalone blockchain demonstrations with the
NeedMoreCoin learning project.

- Add Korean and English sentence, beginner, and advanced examples for the
  same educational cryptocurrency core.
- Add the shared cryptocurrency construction guide and the bilingual example
  authoring/template documents.
- Add regression coverage for the six-way example matrix and retire the old
  standalone blockchain, proof-of-work, signature, and consensus examples.

This is educational single-process code, not a production cryptocurrency or
investment guidance.
