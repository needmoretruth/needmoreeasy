# NME 0.0.1-beta.37

beta.37에서는 이미 존재하는 프로그램 파일의 파일 시스템 오류와 프로그램
없음 진단을 구분합니다.

- 이미 존재하지만 읽을 수 없는 `.nme` 프로그램을 `nme run`과 `nme native`에서
  `파일을 읽을 수 없습니다` E9007로 표시합니다.
- 실제로 없는 경로에는 `프로그램 파일이 없습니다` E9015를 유지합니다.
- 권한이 제한된 프로그램 파일을 사용하는 결정적인 Unix 한영 회귀 검사를
  추가했습니다.

언어 의미와 생성되는 Python 동작은 바뀌지 않습니다.
