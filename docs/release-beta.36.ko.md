# NME 0.0.1-beta.36

beta.36에서는 `nme compile` 준비 단계의 실패와 컴파일러 시작 실패를
구분합니다.

- 임시 작업 폴더가 막혔을 때 네이티브 컴파일러 시작 실패 E9011 대신 E9027
  `임시 작업 폴더를 만들 수 없습니다`를 표시합니다.
- 임시 Python 소스를 저장하지 못하면 E9008로 표시하고, Python/Nuitka를
  시작하지 못한 경우에만 E9011을 유지합니다.
- `TMPDIR`을 파일로 지정하는 결정적인 Unix 한영 회귀 검사를 추가했습니다.

언어 의미와 생성되는 Python 동작은 바뀌지 않습니다.
