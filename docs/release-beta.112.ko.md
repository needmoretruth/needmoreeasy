# NME 0.0.1-beta.112

beta.112에서는 제한된 네이티브 백엔드에 논리 조건을 추가합니다.

- 네이티브 NME 블록 조건에서 지원되는 피연산자를 `and`와 `or`로 묶을 수
  있습니다. 공통 파서는 Python 우선순위를 유지하고 생성된 C는 단락 평가를
  보존합니다.
- 한국어 `그리고`와 `또는`도 같은 언어 중립 조건 트리와 네이티브 하강 경로를
  사용합니다. Python 콜론 조건은 네이티브 코어 밖에 남습니다.
- 영어·한국어 문장형·초급·고급 여섯 회귀 사례, 이중 언어 단락 평가 테스트,
  실행 가능한 쌍 예제, 네이티브 레퍼런스와 가이드를 함께 추가합니다.
